## Purpose

提供面向全部 A 股证券的可恢复批处理边界，把证券身份、行业画像、采集运行、物化结果和缺口按证券隔离，支持从代表性样本扩展到全市场而不把局部成功误报为全量完成。

## ADDED Requirements

### Requirement: 全 A 股批处理必须以唯一身份为边界
系统 MUST 使用证券代码、市场、证券类型和有效期解析唯一 A 股身份；重名、多证券、退市、非 A 股或未支持市场 MUST 在网络 I/O 前标记为不可运行并保留原因。每个证券的运行、快照、事实和报告 MUST 绑定同一 namespace 与身份。批量计划 MUST 沿用版本化八步研究范围，不能因扩大证券数量而重新启用普通日线或未登记用途的接口字段。

#### Scenario: 唯一沪深 A 股
- **WHEN** 证券目录给出唯一有效的沪深 A 股身份
- **THEN** 系统按已登记八步用途、字段和所需历史范围创建该证券的结构化计划并可独立恢复

#### Scenario: 重名或市场冲突
- **WHEN** 查询只能得到多个候选或市场与代码冲突
- **THEN** 系统不发起供应商请求，输出身份前置缺口

### Requirement: 批处理必须有界、幂等并逐证券报告状态
系统 MUST 支持有界并发/单次批量、已提交页复用、失败恢复和逐证券终态；批次汇总 MUST 同时报告成功、部分、失败、无数据和未执行数量，不得因部分证券完成而声明全 A 股完成。

#### Scenario: 中断后恢复
- **WHEN** 批量运行在若干证券完成后中断
- **THEN** 恢复只执行未完成范围，已完成证券的快照、事实和报告保持不变

#### Scenario: 全市场仍有缺口
- **WHEN** 部分行业或来源不可用
- **THEN** 汇总状态为 partial，并按证券、数据集、期间和原因输出可追踪缺口
