## Purpose

让八步研究从结构化事实、业务维度、治理事件和明确假设中生成可复算报告草稿，并逐题展示数据就绪、待补和不适用，避免缺失数据被叙事或评级掩盖。

## ADDED Requirements

### Requirement: 八步报告必须使用统一冻结输入
系统 MUST 为 ES01–ES08 生成固定顺序章节、置顶结论卡和审计附录；网页、Markdown、Excel、PDF 和 HTML MUST 由同一报告版本生成。每个确定性数字 MUST 引用事实 ID 或公式输入，不能只保留格式化后的数字。历史事实、确定性派生、假设和模型判断 MUST 分开保存；追加数据形成新快照和变化说明，模型采用后重审受影响分析，不能静默混合报告、计算及图表版本。

#### Scenario: 完整普通企业输入
- **WHEN** 目标公司存在可消费财务事实、市场快照、行业路由和模型提出且有依据的显式假设
- **THEN** 系统生成八步报告及四种导出，核心数值和数据快照 ID 在各格式一致

#### Scenario: 财务输入缺失
- **WHEN** 关键指标缺少可消费事实或期间不完整
- **THEN** 依赖该输入的问题和估值模型标为待补/失败，报告保留其他有依据的分析与适用估值路径，不输出伪造零值或无依据目标价

### Requirement: 行业适用性和覆盖必须是三值状态
系统 MUST 根据已证实的行业画像选择普通企业、银行、保险、券商、地产、资源、公用事业或未盈利企业的适用模型；未知行业 MUST 不回退为通用企业。每道问题和每一步 MUST 分别给出 `ready`、`pending` 或 `not_applicable`，并列出缺失 requirement 和下一步补采路径。

#### Scenario: 银行公司
- **WHEN** 身份和行业画像证据将公司路由为银行
- **THEN** 报告可使用 PB/股利折现/剩余收益路径，并将通用企业 DCF 标为不适用

#### Scenario: 行业未知
- **WHEN** 行业证据不足或分类互相矛盾
- **THEN** 行业步骤和依赖行业模型保持待补，不自动使用普通企业模型关闭缺口

### Requirement: 模型必须自主形成研究判断与估值假设
Codex／Claude Code MUST 负责比较证据、解释数据、提出假设、选择适用方法、给出估值或研究评级并撰写正文；框架 MUST 接收该研究成果，不得以固定句式或规则生成的观察代替判断。用户未逐项确认 MUST NOT 阻止模型提出假设、计算估值及给出评级。假设 MUST 记录提出者、数值或范围、依据、适用条件和版本，与事实区分；数值计算 MUST 引用冻结输入和公式。报告 MUST 说明结论、证据和改变结论的条件，不生成交易指令。

#### Scenario: 无用户填写的预测参数
- **WHEN** 历史事实和适用模型的必要输入足以支持有范围的预测，用户未提供增长率或折现率
- **THEN** 模型自主提出并解释参数，调用计算输出情景、敏感性、合理价值区间和明确研究评级，不以等待用户确认结束

#### Scenario: 关键证据不足
- **WHEN** 缺少不可替代的估值输入或证据有未解决冲突
- **THEN** 模型说明哪项判断受影响，调用有界补采或选择有依据的替代方法；仍不足时明确该项不能判断的范围和缺失证据，保留其他有依据的结论，不伪造目标价

#### Scenario: 没有模型研究成果
- **WHEN** 数据已准备但尚未收到模型撰写的判断和正文
- **THEN** 框架返回 analysis_pending，规则观察只作研究输入，不将非空判断对象或自动摘要视为正式研究完成

### Requirement: 框架必须完成研究任务的数据准备与恢复
系统 MUST 接受公司标识、研究截止日和范围作为高层任务输入，在内部处理来源定位、缓存选择、必要补采、计算整理和紧凑打包。模型 MUST 无需查找 URL、供应商参数或手工拼接数据目录。系统 MUST 返回任务标识、分层状态、包位置及按受影响问题归并的缺口，支持有界执行、恢复和状态查询；补采 MUST 沿用来源门禁和研究范围，处理缺口不得触发重复下载。

#### Scenario: 从公司开始研究
- **WHEN** 模型提交唯一公司和研究任务且允许该任务范围内联网
- **THEN** 框架自动复用缓存、取得必要输入并整理核心包；返回 ready 或有明确原因的 partial，不要求模型逐个选择源或本地投影

#### Scenario: 网络失败及恢复
- **WHEN** 有界执行中某来源失败或进程中断
- **THEN** 框架保留已完成结果与检查点，按既有重试及备选策略恢复；预算耗尽返回具体缺口，不无期限循环，不让模型手工修复采集管道

#### Scenario: 有数据但处理尚未支持
- **WHEN** 原件已缓存但某语义整理或计算路线未实现
- **THEN** 系统报告处理或计算缺口及受影响判断，不称来源无数据，不重复下载已有原件

### Requirement: 知识必须按需提供且具有可核查出处
系统 MUST 提供按研究问题检索与有界读取的知识接口，条目包含作者、题名、版本或年份、原始出处、页或章节定位、概念、适用条件、局限及反例。知识读取 MUST 可选；经典和诺奖相关理论 MUST 按问题适用性选择，不能要求全部预载。skeleton 或无法核实出处的条目 MUST NOT 作为已验证知识引用。

#### Scenario: 模型需要解释资本结构或现金流估值
- **WHEN** 模型按问题查询理论
- **THEN** 框架返回相关已核实条目索引并支持定向读取；无可用条目返回具体知识缺口，不杜撰出处或用骨架充数

#### Scenario: 无需知识库即可形成研究
- **WHEN** 模型能够基于数据与自身推理完成问题且未请求知识
- **THEN** 框架允许继续写作，不强制引用经典、诺奖或加载整套教材

### Requirement: 正式报告必须以模型正文和必要图表呈现
报告 MUST 以结论、解释和支持判断的图表为主体，详细表格、内部编号与完整来源记录进入附录。模型 MUST 能提交图表用途并调用确定性绘图与组装；图表 MUST 引用同一冻结事实或计算结果，具有正确期间、单位与来源。最终报告 MUST 经过模型阅读与渲染检查，不能以机器导出成功代替人读验收。

#### Scenario: 贵州茅台黄金报告
- **WHEN** 模型完成八步分析并提交正文及绘图需求
- **THEN** 成品展示收入利润趋势、利润现金流比较和适用估值敏感性，说明主要变化的研究含义；各格式结论和核心数字一致，正文不以长表、ID和通用待分析语句堆砌

#### Scenario: 图表存在期间缺口
- **WHEN** 某期没有可消费数据
- **THEN** 图表标示缺失而不补零或混用累计与单季，正文结论不将断点解释为经营变化

#### Scenario: 用户拒绝阅读体验
- **WHEN** 自动数字及导出检查通过但用户指出内容只是在罗列数据
- **THEN** 报告人读验收保持未通过，保留已验证数值成果并重新完成模型研究、排版与阅读，不声称只剩签署

### Requirement: 研究工具必须提供可消费内容与完整交互闭环
系统 MUST 通过MCP暴露高层研究动作，CLI与其共享业务行为，模型无需操纵来源或数据库路径。工具 MUST 支持公司首包、持久任务状态/恢复、指标/同行查询、证据读取、按需知识、补采、计算、章节保存、两类绘图、报告组装和成品查看。输入 MUST 接受明确范围与研究问题，未知需求返回能力缺口。结果 MUST 包含研究/快照标识、分层状态、可读内容、具体缺口及可操作续读/恢复信息，不能只返回难以访问的文件路径。

#### Scenario: 一句话开始并继续深入
- **WHEN** 用户仅指定唯一公司，模型发起研究并随后查询现金流质量问题
- **THEN** 框架固定实际截止时间，返回紧凑首包或可恢复任务，再按问题提供同口径材料与原文引用；模型无需选供应商或数据目录

#### Scenario: 两个宿主读取最终成品
- **WHEN** Codex或Claude Code调用组装和成品查看
- **THEN** 对应宿主获得真实报告及能实际查看的渲染页面；各宿主单独保存验收证据，文件存在或另一宿主成功不能代替

### Requirement: 标准研究必须按判断需要深入且支持有界恢复
系统 MUST 默认支持完成有明确判断的标准报告，不以研究总耗时作为缩减质量的门槛。初次研究 MUST 覆盖已选核心范围；后续深入 MUST 说明新资料可能如何实质改变评级、估值或重大风险判断，无此影响的扩展不默认执行。单次采集/计算/沙盒 MUST 有可配置执行上限、超时及持久检查点，超限不得冒充研究完成；同因失败不得无限重试或另开任务绕过来源门禁。

#### Scenario: 单次运行上限到达
- **WHEN** 关键研究仍需推进但一次工具执行达到上限
- **THEN** 保存结果及恢复位置，返回可恢复状态；后续从检查点继续，不因累计耗时较长省略必要分析或标为完成

#### Scenario: 追加资料不改变关键判断
- **WHEN** 模型已完成标准分析且拟补资料没有可说明的评级、估值或重大风险影响
- **THEN** 不扩展默认补采，完成并检查报告；未解决的实质问题列明影响与处置，不能为定稿隐去

#### Scenario: 同一外部阻塞持续存在
- **WHEN** 既有来源重试及适用备选已耗尽且没有新执行条件
- **THEN** 保留阻塞事实与依赖判断，完成其他有依据的结论；恢复需有可执行条件变化，不无限轮询，不把缺证据解释成无风险

### Requirement: 知识卡必须区分来源依据与阅读触发线索
知识条目 MUST 使用结构化Markdown，包含概念与公式、商业场景、触发指标、反例与失效边界，并记录作者、题名、版本、出处/定位、内容性质和核实状态。长度建议800—1500字，MUST NOT 为字数删除必要条件。触发阈值 MUST 标明来源、适用行业及口径，不能作为普适评级规则。目录 MUST 支持有界检索/分页，搜索后能读到真实正文，不强制预载全库。

#### Scenario: 触发阈值缺乏通用依据
- **WHEN** 条目将ROIC超过某数值作为阅读线索但仅适用特定行业或口径
- **THEN** 展示限定条件，不自动判断护城河或评级；无出处阈值不得冒充理论定律

#### Scenario: 知识目录扩大
- **WHEN** 全目录超出轻量索引预算
- **THEN** 返回分组或分页及继续读取方式，不静默丢弃条目或把超量结果称为几百token

### Requirement: 常规与定制图表必须共享可追溯产物合同
系统 MUST 提供按适用数据生成的常规候选目录和模型定制绘图路径，由模型选择入文。两路 MUST 保存图片、图表ID、底层数据、快照、来源、代码或模板版本及检查状态。定制绘图 MUST 使用当前研究的只读数据，常规财务计算 MUST 引用正式计算结果，不在绘图脚本重新定义公式或联网取数。

#### Scenario: 常规图输入不足或跨度不同
- **WHEN** 只有五个年度观测值，或杜邦口径不匹配，或现金流桥所需调整项缺失
- **THEN** CAGR按实际间隔计算；不匹配的杜邦和无法勾稽的现金流桥返回具体不足，不混淆现金余额桥与净利润调节桥，不为图形完整编造数值

#### Scenario: 定制图加入正文
- **WHEN** 模型请求有研究用途的定制Python图
- **THEN** 沙盒仅读取批准快照，保存绘图代码/数据与检查结果，模型实际查看图片后引用图表ID；运行成功不能替代图义或数据检查

### Requirement: 探索计算必须独立验证后才能用于正式结论
系统 MUST 允许模型编写新指标/算法的探索计算，但其结果与正式指标分开保存。未验证结果 MUST NOT 冒充正式指标、写入正式指标库或成为正式估值/评级数值依据。验证 MUST 核查定义及适用性、输入/单位/期间、独立复算或参考结果、边界失败行为和重复执行；代码成功或同一实现自证不算验证。通过结果用于报告 MUST 明示探索性质、方法及限制；反复使用的方法经版本化及回归后方可沉淀。

#### Scenario: 新算法仅运行成功
- **WHEN** 沙盒产出一个非现有规则的指标但尚无独立验证
- **THEN** 保存为未验证探索，拒绝作为正式估值或评级数值依据，列出待验证项，不自动注册为标准方法

#### Scenario: 经验证探索进入报告或沉淀
- **WHEN** 探索计算已有完整验证证据并可重复执行
- **THEN** 可作为标注性质和限制的报告依据；晋升常规处理规则还需独立版本、方法说明及回归证据，重复使用次数本身不能替代准入

### Requirement: 正文必须支持增量保存与引用组装
系统 MUST 接收模型Markdown正文、图表/数值/证据引用及少量报告信息，支持按章节保存、修订与恢复。关键财务数字 MUST 能从冻结事实或计算结果引用替换；程序只做计算校验与呈现，不替模型改写判断。引用缺失、快照混用和图文数据冲突 MUST 阻止正式定稿或明确退回修复，不能静默替换。

#### Scenario: 修改章节后重新组装
- **WHEN** 模型只修改一章文字或图表摆放且数据未变
- **THEN** 保留其他章节及既有计算，生成新的报告版本，不重采数据；HTML/PDF/Markdown/Excel核心内容一致，明细及完整血缘在附录

#### Scenario: 引用不存在或指向其他快照
- **WHEN** 正文短引用缺失或引用不兼容的图表/计算版本
- **THEN** 返回具体章节与引用错误，不用占位值、零值或最新数据静默补齐
