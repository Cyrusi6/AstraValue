## Purpose

让八步研究从结构化事实、业务维度、治理事件和明确假设中生成可复算报告草稿，并逐题展示数据就绪、待补和不适用，避免缺失数据被叙事或评级掩盖。

## ADDED Requirements

### Requirement: 八步报告必须使用统一冻结输入
系统 MUST 为 ES01–ES08 生成固定顺序章节、置顶结论卡和审计附录；网页、Markdown、Excel、PDF 和 HTML MUST 由同一报告版本生成。每个确定性数字 MUST 引用事实 ID 或公式输入，不能只保留格式化后的数字。历史事实、确定性派生、假设和模型判断 MUST 分开保存；追加数据形成新快照和变化说明，模型采用后重审受影响分析，不能静默混合报告、计算及图表版本。

#### Scenario: 完整普通企业输入
- **WHEN** 目标公司存在可消费财务事实、市场快照、行业路由和模型提出且有依据的显式假设
- **THEN** 系统生成八步报告及四种导出，核心数值和数据快照 ID 在各格式一致

#### Scenario: 财务输入缺失
- **WHEN** 关键指标缺少可消费事实或期间不完整
- **THEN** 依赖该输入的问题和估值模型标为待补/失败，报告保留其他有依据的分析与适用估值路径，不输出伪造零值或无依据目标价

### Requirement: 行业适用性和覆盖必须是三值状态
系统 MUST 根据已证实的行业画像选择普通企业、银行、保险、券商、地产、资源、公用事业或未盈利企业的适用模型；未知行业 MUST 不回退为通用企业。每道问题和每一步 MUST 分别给出 `ready`、`pending` 或 `not_applicable`，并列出缺失 requirement 和下一步补采路径。

#### Scenario: 银行公司
- **WHEN** 身份和行业画像证据将公司路由为银行
- **THEN** 报告可使用 PB/股利折现/剩余收益路径，并将通用企业 DCF 标为不适用

#### Scenario: 行业未知
- **WHEN** 行业证据不足或分类互相矛盾
- **THEN** 行业步骤和依赖行业模型保持待补，不自动使用普通企业模型关闭缺口

### Requirement: 完整财务报表按需可读且空白状态有据
系统 MUST 在精简首包之外提供完整合并三大报表目录与有界续读，保留期间、列头、原文页码和来源。原表金额栏确认留空 MUST 记录为disclosed_blank，不再作为未处理缺口，也 MUST NOT 默认为数值零或不适用；未完成原文核对的继续待补。采用核对结果 MUST 生成新快照，历史报告保持不变。

#### Scenario: 模型读取精简包之外的报表项目
- **WHEN** 模型选择目录中的期间和报表并沿next_page续读
- **THEN** 可读取该表全部原文，合并报表不混入母公司或后续期初调整表，附注可按原件页码继续读取

#### Scenario: 基础指标原表留空
- **WHEN** 原件哈希、公司与期间核对通过且对应表格当前金额单元格确认为空
- **THEN** 保存原行与定位，状态为disclosed_blank；不生成零值事实，无法识别或无证据的字段继续pending

### Requirement: 正文比例必须可通过代码计算与引用

研报中的累计提价幅度、年度分红率和股息率 MUST 可通过共享计算工具取得。计算 MUST 从同快照事实或经原件哈希核验的公司披露中解析输入，保留公式版本与定义；预测派息 MUST 由模型明确提供增长假设及期间，不将历史分红默认为未来收益。正文 MUST 支持计算结果数值引用替换。

#### Scenario: 现金分配与提价比例由代码执行
- **WHEN** 模型选择同产品衔接的两份调价公告、年度分红披露、同年利润及参考股本股价
- **THEN** 工具计算累计提价、分红率和历史股息率；有明确未来十二个月派息假设才生成预测股息率，保留独立记录；不匹配年份、产品或无效分母被拒绝

#### Scenario: 正文直接引用比例计算
- **WHEN** 正文引用当前快照计算ID的value字段
- **THEN** 组装器以百分数呈现并保留计算来源；不存在的计算或字段不被替换为猜测数值

### Requirement: 模型必须自主形成研究判断与估值假设
Codex／Claude Code MUST 负责比较证据、解释数据、提出假设、选择适用方法、给出估值或研究评级并撰写正文；框架 MUST 接收该研究成果，不得以固定句式或规则生成的观察代替判断。用户未逐项确认 MUST NOT 阻止模型提出假设、计算估值及给出评级。假设 MUST 记录提出者、数值或范围、依据、适用条件和版本，与事实区分；数值计算 MUST 引用冻结输入和公式。报告 MUST 说明结论、证据和改变结论的条件，不生成交易指令。

#### Scenario: 无用户填写的预测参数
- **WHEN** 历史事实和适用模型的必要输入足以支持有范围的预测，用户未提供增长率或折现率
- **THEN** 模型自主提出并解释参数，调用计算输出情景、敏感性、合理价值区间和明确研究评级，不以等待用户确认结束

#### Scenario: 关键证据不足
- **WHEN** 缺少不可替代的估值输入或证据有未解决冲突
- **THEN** 模型说明哪项判断受影响，调用有界补采或选择有依据的替代方法；仍不足时明确该项不能判断的范围和缺失证据，保留其他有依据的结论，不伪造目标价

#### Scenario: 没有模型研究成果
- **WHEN** 数据已准备但尚未收到模型撰写的判断和正文
- **THEN** 框架返回 analysis_pending，规则观察只作研究输入，不将非空判断对象或自动摘要视为正式研究完成

### Requirement: 框架必须完成研究任务的数据准备与恢复
系统 MUST 接受公司标识、研究截止日和范围作为高层任务输入，在内部处理来源定位、缓存选择、必要补采、计算整理和紧凑打包。模型 MUST 无需查找 URL、供应商参数或手工拼接数据目录。系统 MUST 返回任务标识、分层状态、包位置及按受影响问题归并的缺口，支持有界执行、恢复和状态查询；补采 MUST 沿用来源门禁和研究范围，处理缺口不得触发重复下载。

#### Scenario: 从公司开始研究
- **WHEN** 模型提交唯一公司和研究任务且允许该任务范围内联网
- **THEN** 框架自动复用缓存、取得必要输入并整理核心包；返回 ready 或有明确原因的 partial，不要求模型逐个选择源或本地投影

#### Scenario: 网络失败及恢复
- **WHEN** 有界执行中某来源失败或进程中断
- **THEN** 框架保留已完成结果与检查点，按既有重试及备选策略恢复；预算耗尽返回具体缺口，不无期限循环，不让模型手工修复采集管道

#### Scenario: 有数据但处理尚未支持
- **WHEN** 原件已缓存但某语义整理或计算路线未实现
- **THEN** 系统报告处理或计算缺口及受影响判断，不称来源无数据，不重复下载已有原件

### Requirement: 知识必须按需提供且具有可核查出处
系统 MUST 提供按研究问题检索与有界读取的知识接口，条目包含作者、题名、版本或年份、原始出处、页或章节定位、概念、适用条件、局限及反例。知识读取 MUST 可选；经典和诺奖相关理论 MUST 按问题适用性选择，不能要求全部预载。skeleton 或无法核实出处的条目 MUST NOT 作为已验证知识引用。

#### Scenario: 模型需要解释资本结构或现金流估值
- **WHEN** 模型按问题查询理论
- **THEN** 框架返回相关已核实条目索引并支持定向读取；无可用条目返回具体知识缺口，不杜撰出处或用骨架充数

#### Scenario: 无需知识库即可形成研究
- **WHEN** 模型能够基于数据与自身推理完成问题且未请求知识
- **THEN** 框架允许继续写作，不强制引用经典、诺奖或加载整套教材

### Requirement: 正式报告必须以模型正文和必要图表呈现

新写作入口 MUST 使用同一版本买方研究主提示，不按宿主另设研究角色。章节保存 MUST 只要求正文、判断及引用，不强制逐章反证、未知项和失效条件；第1—4章不得设置自辩小节。全篇风险与评级失效条件 MUST 在第6章集中插入一次，risk_summary最多300个非空白字符。历史草稿及报告 MUST 可读，不自动改写。

#### Scenario: 不含章节反证也可保存
- **WHEN** 模型提交有效章节正文、判断及引用，未提供counter_evidence、unknowns、invalidation
- **THEN** 新写作接口正常保存，工具schema不再暴露这些章节字段，风险在结论提交时全局收集

#### Scenario: 数据问题不进入正文
- **WHEN** 同行指标缺期间类型或归属口径，或者多个主体的比较定义不一致
- **THEN** 写作视图排除相关指标，原始值与质检记录保留；不将未核实值默认对齐，不将无来源的75%等默认参数当行业共识

#### Scenario: 基于假设推进研究
- **WHEN** 缺少微观经营颗粒度而模型能够提出合理情景
- **THEN** 允许模型明确设定假设并调用确定性计算；审阅不因合理推论尚未成为事实而要求免责段落，事实引用和算术错误仍修正

报告 MUST 以结论、解释和支持判断的图表为主体，详细表格、内部编号与完整来源记录进入附录。模型 MUST 能提交图表用途并调用确定性绘图与组装；图表 MUST 引用同一冻结事实或计算结果，具有正确期间、单位与来源。最终报告 MUST 经过模型阅读与渲染检查，不能以机器导出成功代替人读验收。

#### Scenario: 贵州茅台黄金报告
- **WHEN** 模型完成八步分析并提交正文及绘图需求
- **THEN** 成品展示收入利润趋势、利润现金流比较和适用估值敏感性，说明主要变化的研究含义；各格式结论和核心数字一致，正文不以长表、ID和通用待分析语句堆砌

#### Scenario: 图表存在期间缺口
- **WHEN** 某期没有可消费数据
- **THEN** 图表标示缺失而不补零或混用累计与单季，正文结论不将断点解释为经营变化

#### Scenario: 用户拒绝阅读体验
- **WHEN** 自动数字及导出检查通过但用户指出内容只是在罗列数据
- **THEN** 报告人读验收保持未通过，保留已验证数值成果并重新完成模型研究、排版与阅读，不声称只剩签署

### Requirement: 研究工具必须提供可消费内容与完整交互闭环
系统 MUST 通过MCP暴露高层研究动作，CLI与其共享业务行为，模型无需操纵来源或数据库路径。工具 MUST 支持公司首包、持久任务状态/恢复、指标/同行查询、证据读取、按需知识、补采、计算、章节保存、两类绘图、报告组装和成品查看。输入 MUST 接受明确范围与研究问题，未知需求返回能力缺口。结果 MUST 包含研究/快照标识、分层状态、可读内容、具体缺口及可操作续读/恢复信息，不能只返回难以访问的文件路径。

#### Scenario: 一句话开始并继续深入
- **WHEN** 用户仅指定唯一公司，模型发起研究并随后查询现金流质量问题
- **THEN** 框架固定实际截止时间，返回紧凑首包或可恢复任务，再按问题提供同口径材料与原文引用；模型无需选供应商或数据目录

#### Scenario: 两个宿主读取最终成品
- **WHEN** Codex或Claude Code调用组装和成品查看
- **THEN** 对应宿主获得真实报告及能实际查看的渲染页面；各宿主单独保存验收证据，文件存在或另一宿主成功不能代替

### Requirement: 标准研究必须按判断需要深入且支持有界恢复
系统 MUST 默认支持完成有明确判断的标准报告，不以研究总耗时作为缩减质量的门槛。初次研究 MUST 覆盖已选核心范围；后续深入 MUST 说明新资料可能如何实质改变评级、估值或重大风险判断，无此影响的扩展不默认执行。单次采集/计算/沙盒 MUST 有可配置执行上限、超时及持久检查点，超限不得冒充研究完成；同因失败不得无限重试或另开任务绕过来源门禁。

#### Scenario: 单次运行上限到达
- **WHEN** 关键研究仍需推进但一次工具执行达到上限
- **THEN** 保存结果及恢复位置，返回可恢复状态；后续从检查点继续，不因累计耗时较长省略必要分析或标为完成

#### Scenario: 追加资料不改变关键判断
- **WHEN** 模型已完成标准分析且拟补资料没有可说明的评级、估值或重大风险影响
- **THEN** 不扩展默认补采，完成并检查报告；未解决的实质问题列明影响与处置，不能为定稿隐去

#### Scenario: 同一外部阻塞持续存在
- **WHEN** 既有来源重试及适用备选已耗尽且没有新执行条件
- **THEN** 保留阻塞事实与依赖判断，完成其他有依据的结论；恢复需有可执行条件变化，不无限轮询，不把缺证据解释成无风险

### Requirement: 知识卡必须区分来源依据与阅读触发线索
知识条目 MUST 使用结构化Markdown，包含概念与公式、商业场景、触发指标、反例与失效边界，并记录作者、题名、版本、出处/定位、内容性质和核实状态。长度建议800—1500字，MUST NOT 为字数删除必要条件。触发阈值 MUST 标明来源、适用行业及口径，不能作为普适评级规则。目录 MUST 支持有界检索/分页，搜索后能读到真实正文，不强制预载全库。

#### Scenario: 触发阈值缺乏通用依据
- **WHEN** 条目将ROIC超过某数值作为阅读线索但仅适用特定行业或口径
- **THEN** 展示限定条件，不自动判断护城河或评级；无出处阈值不得冒充理论定律

#### Scenario: 知识目录扩大
- **WHEN** 全目录超出轻量索引预算
- **THEN** 返回分组或分页及继续读取方式，不静默丢弃条目或把超量结果称为几百token

### Requirement: 常规与定制图表必须共享可追溯产物合同
系统 MUST 提供按适用数据生成的常规候选目录和模型定制绘图路径，由模型选择入文。两路 MUST 保存图片、图表ID、底层数据、快照、来源、代码或模板版本及检查状态。定制绘图 MUST 使用当前研究的只读数据，常规财务计算 MUST 引用正式计算结果，不在绘图脚本重新定义公式或联网取数。

#### Scenario: 常规图输入不足或跨度不同
- **WHEN** 只有五个年度观测值，或杜邦口径不匹配，或现金流桥所需调整项缺失
- **THEN** CAGR按实际间隔计算；不匹配的杜邦和无法勾稽的现金流桥返回具体不足，不混淆现金余额桥与净利润调节桥，不为图形完整编造数值

#### Scenario: 定制图加入正文
- **WHEN** 模型请求有研究用途的定制Python图
- **THEN** 沙盒仅读取批准快照，保存绘图代码/数据与检查结果，模型实际查看图片后引用图表ID；运行成功不能替代图义或数据检查

### Requirement: 探索计算必须独立验证后才能用于正式结论
系统 MUST 允许模型编写新指标/算法的探索计算，但其结果与正式指标分开保存。未验证结果 MUST NOT 冒充正式指标、写入正式指标库或成为正式估值/评级数值依据。验证 MUST 核查定义及适用性、输入/单位/期间、独立复算或参考结果、边界失败行为和重复执行；代码成功或同一实现自证不算验证。通过结果用于报告 MUST 明示探索性质、方法及限制；反复使用的方法经版本化及回归后方可沉淀。

#### Scenario: 新算法仅运行成功
- **WHEN** 沙盒产出一个非现有规则的指标但尚无独立验证
- **THEN** 保存为未验证探索，拒绝作为正式估值或评级数值依据，列出待验证项，不自动注册为标准方法

#### Scenario: 经验证探索进入报告或沉淀
- **WHEN** 探索计算已有完整验证证据并可重复执行
- **THEN** 可作为标注性质和限制的报告依据；晋升常规处理规则还需独立版本、方法说明及回归证据，重复使用次数本身不能替代准入

### Requirement: 正文必须支持增量保存与引用组装
系统 MUST 接收模型Markdown正文、图表/数值/证据引用及少量报告信息，支持按章节保存、修订与恢复。关键财务数字 MUST 能从冻结事实或计算结果引用替换；程序只做计算校验与呈现，不替模型改写判断。引用缺失、快照混用和图文数据冲突 MUST 阻止正式定稿或明确退回修复，不能静默替换。

#### Scenario: 修改章节后重新组装
- **WHEN** 模型只修改一章文字或图表摆放且数据未变
- **THEN** 保留其他章节及既有计算，生成新的报告版本，不重采数据；HTML/PDF/Markdown/Excel核心内容一致，明细及完整血缘在附录

#### Scenario: 引用不存在或指向其他快照
- **WHEN** 正文短引用缺失或引用不兼容的图表/计算版本
- **THEN** 返回具体章节与引用错误，不用占位值、零值或最新数据静默补齐

### Requirement: 首包目录按研究用途筛选并支持逐层读取
首包 MUST 只显示各类有用资料的摘要、期间范围、可用状态和读取入口。模型 MUST 能按类别展开到具体报表、附注、公告、数据集及字段，再读取所选条目或期间。公开状态 MUST 统一为已有正式数值、已有原文、已核实无事项、已有替代资料、尚未取得、待处理，按资料及期间解释；内部供应商原状态不改写。缓存清单核对和不纳入原因 MUST 只交付用户，不进入模型首包，也不暴露为模型审计工具。

#### Scenario: 轻量首包与字段下钻
- **WHEN** 模型启动研究并选择一个数据集
- **THEN** 首包不加载全部事实/证据，目录可继续展开字段，模型按需读取字段及期间；原始字段保留数值使用边界

#### Scenario: 逐项核对但不向模型灌入排除记录
- **WHEN** 数据准备流程核对登记缓存及当前快照
- **THEN** 每个缓存原件/记录都有目录去向或排除原因供用户检查，程序性通知、重复摘要和无研究用途材料不默认入选；模型仅获得有用条目和读取入口

#### Scenario: 同主题跨期读取
- **WHEN** 模型展开附注主题或标准指标
- **THEN** 二级同主题跨期资料合为一个入口，支持的数值表直接按期间对齐，保留单位、口径、逐格来源及逐期原文；不同累计区间和单季分表。冲突不覆盖、空白不补零；不支持的复杂表格显示原文可读和已整理期间，不冒充全部结构化。附注定位须识别真实章节标题，排除正文交叉引用并止于下一附注或章节。

#### Scenario: 附注含多子表或跨页续表
- **WHEN** 一主题包含多层表头、不同含义的同名行或跨页金额表
- **THEN** 代码自动保留子表名称、行层级、列头路径、报告期及原件单元格定位，金额、比例、文字和原表空白分别呈现。检测到的子表逐项计数，单期全部检测表处理与部分处理分开；首张表提取成功不得代表整主题完成。模型可按子表ID有界读取，不必加载全部明细；未识别的表进入待处理状态而非补零或静默丢弃。

#### Scenario: 替代资料统一目录可用状态
- **WHEN** 供应商字段为空，但同公司同期间已有原件核实空白、正式指标或可定位原文
- **THEN** 目录按实际已有路径显示可读期间与入口，空白仍为null，原文可读不等于数值已准入；其他历史期间保留原状态，不将部分单季指标等同完整报表数据集。投影幂等且不改写冻结原件，读取前核对来源哈希。

### Requirement: 按研究需要注册附注计算公式
系统 MUST 通过共享calculate入口按报告期选择附注输入，不接收模型手填金额。每种新增方法 MUST 明确公式、适用表式、期间/单位/合并范围及输入定位，核对原件哈希和单元格数值，校验合计或勾稽后保存版本化计算结果；通用附注可读不代表全部已进入正式计算。

#### Scenario: 存货构成与减值率
- **WHEN** 请求inventory_composition或inventory_allowance_ratio
- **THEN** 代码分别计算分类净额/总净额，以及减值准备/账面余额；在产品和自制半成品均单列时才返回两者合计占比。空白不补零，歧义、错单位、缺分母、分项不合计或余额减准备不等于净额拒绝产出。非零微小比例在正文中不得被显示为零。

#### Scenario: API空返回后按年报核实事件适用状态
- **WHEN** 担保或重大诉讼接口无记录，当前冻结年度报告在准确章节明确选择不适用或无重大诉讼仲裁
- **THEN** 目录按该报告年度提供核查原文、页码及来源，空接口不自行产生否定结论；违规担保、关联担保不替代总体担保章节，普通案件不与重大诉讼混同，未核查年度保持原状态，其他公司勾选适用不得判无事项。

#### Scenario: API补充记录与中报核查接入同一目录
- **WHEN** 当前研究登记同公司、有响应哈希及成功协议证据的审计意见/监管API记录，或年报中报提供原缺失主题的明确原文
- **THEN** 按报告期/公告日期接入有界读取入口，排除截止日之后披露的记录，不覆盖冻结事实；审计意见替代路径不认定供应商空字段同义，监管记录保留重复观察和最新原文，不能用旧API记录覆盖较新披露。客户集中度不等于全部实名、前十名股东质押表不等于全部股东，未知保持未知，报告期内无发行/限售变动不外推未来。

#### Scenario: 申万分类以替代资料提供而不覆写供应商空字段
- **WHEN** 同公司研究取得可核验的申万二级分类目录和成分记录
- **THEN** 系统单独保存分类版本、层级、行业名称、上级行业及行业指数代码，两个原供应商空字段显示“已有替代分类资料，原供应商字段为空”并指向同一读取入口。代码命名空间保持独立，不将指数代码静默填为供应商分类代码；观察日期晚于研究截止日时明确为补充参考，不回填历史归属。公司、原件哈希、二级目录唯一匹配及完整成分校验失败时拒绝登记。


### Requirement: 补充分类与API资料必须自动查询核验登记
公开prepare_research MUST 在核心包就绪后自动复用或准备申万替代分类。request_materials MUST 支持模型仅选择研究材料类型，由框架完成请求、校验、登记并返回可恢复任务；不要求模型指定URL、供应商或文件。登记 MUST 绑定当前公司/研究/快照，不改写冻结事实；公司不匹配、来源篡改、不完整分页及不符合披露截止日的资料不得准入。

#### Scenario: 换公司准备申万替代分类
- **WHEN** 新公司已有核心包但没有登记申万分类
- **THEN** 根据二级目录与完整成分发现归属，自动登记；原供应商字段仍为空，指数代码保持独立，当前观察不得冒充截止日历史分类。离线模式不启动网络。

#### Scenario: 补充请求恢复并自动更新目录
- **WHEN** 模型请求审计意见或治理API资料，网络失败或处理到执行上限
- **THEN** 持久化已完成页/行业，get_task只读，resume_task继续；同需求变更问题措辞不绕过失败预算。完成后目录立即提供新增读取入口，重复同请求复用结果。空响应保存查询回执但不认定无事项，其他原文核查结果按范围保留。

#### Scenario: 对外状态按期间一致
- **WHEN** 一项资料同时存在正式数值、原文、替代资料或不同期间的明确无事项
- **THEN** 首包计数、目录状态和按期间读取共用六态规则，混合集合不宣称全部正式数值或全部无事项；原表空白不成为零或无事项，未覆盖期间保留待处理/尚未取得，原供应商兼容状态不覆盖公开状态。


### Requirement: Python执行边界与产物必须可核验
系统 MUST 通过隔离进程环境执行模型Python代码，只提供选择后的当前快照数据，禁止访问项目事实库及联网。系统 MUST 限制单次运行时间、内存、CPU、进程及输出大小，保存代码、输入、运行环境摘要与失败原因；沙盒不可用时不得回退宿主机直接执行。默认不为单次研究扩大依赖安装或挂载整个工作区。

#### Scenario: 代码尝试越过数据或资源边界
- **WHEN** 代码尝试联网、修改只读输入、写入未授权路径或超出运行资源
- **THEN** 运行环境拒绝或终止，结果保留失败状态，冻结研究数据不变；输出提取拒绝符号链接、路径穿越及超量文件，不将残缺结果登记为成功

#### Scenario: 查看定制图后进行报告引用
- **WHEN** 模型引用定制图到正文
- **THEN** 必须有同一图片、代码与数据哈希的查看及图义/数据检查记录；图表未检查或发生变化拒绝组装。未引用的其他实验不阻止报告生成

#### Scenario: 独立代码验证探索结果
- **WHEN** 模型提交探索计算及复算代码
- **THEN** 检查定义、适用条件、单位/期间，不同实现复算完整结果并重跑原实现，通过明确预期的成功和失败边界后才能成为经验证探索。相同实现换注释、仅填检查通过或缺乏边界样例均不通过；即使通过也不自动晋升正式指标

### Requirement: 研究审阅必须检验关键假设与投资回报的连接
统一主提示与审阅提示 MUST 引导模型解释关键预测幅度的经营依据，区分盈利预测期、价值对应时点和评价持有期，并在分红构成投资理由时讨论同期间现金与价格回报。审阅 MUST 允许有依据的自主情景，不强迫改用指定参数或逐章追加反证；工具算术验证不得替代研究论证。历史报告 MUST 保持原样，新提示的完整研究效果与技术回归分开验收。

#### Scenario: 反推目标经过算术验证
- **WHEN** 模型从全年假设反推出剩余期间的利润要求，并通过独立复算
- **THEN** 将其用于检验达标难度，仍需用经营事实或明确情景解释可达路径，不将复算通过称为预测已获证实

#### Scenario: 分红与估值期限不同
- **WHEN** 正文把未来十二个月股息率与未指定时点的合理价值并列用于最终评级
- **THEN** 审阅要求先明确统一评价期限，再由代码计算适用的回报；不直接相加，也不因此强制改变评级

### Requirement: 调用规则与恢复方式必须可发现
CLI与MCP MUST 从共享操作契约暴露参数类型及分页边界；CLI MUST 支持任务给定的独立配置和操作Schema查询，不要求宿主编写临时业务调用器。参数错误 MUST 指明具体字段与有效范围，未知指标给出当前主题的已注册ID和读取入口，不将拼写错误直接解释为采集缺失。

#### Scenario: 原任务的分页和指标名称错误重现
- **WHEN** 模型请求超过分页上限或使用未注册指标ID
- **THEN** 返回字段级修复信息或真实可用ID；不静默截断、猜测指标替换或自动补采。期间类型误筛空集时可返回可用类型及事实日期提示，但不自动扩宽查询

#### Scenario: 宿主未直接注入研究MCP
- **WHEN** 模型使用共享CLI和任务提供的配置文件
- **THEN** 可以描述操作Schema、使用同一服务执行，并保留缺失/类型错误的可读JSON返回；既有调用形式继续可用

### Requirement: 金融提示与任务参数及工程说明必须分离
所有宿主 MUST 共用金融研究和审阅提示；提示保留自主假设、估值与回报、八章写作及成品检查要求，工具部分只保留必要入口和使用原则。公司任务消息 MUST 只提供公司、截止日、资料范围、研究/快照标识、工具入口和交付参数，不另立金融规范或默认追加框架验收、双版本实验。详细工具契约 MUST 按需可查，不能因压缩提示丢失操作信息。

#### Scenario: 启动单次公司研究
- **WHEN** 用户要求使用已准备资料完成一份公司研报
- **THEN** 启动消息引用统一提示并提供必要参数；研究模型不默认加载开发计划、OpenSpec任务及历史测试，不被要求修改框架或对照旧版本。真实工程故障另行记录处理，参数错误仍可按工具说明恢复

#### Scenario: 需要具体公式或引用语法
- **WHEN** 研究模型需要调用计算、读取附注或保存图文
- **THEN** 从当前Schema和按需工具参考读取对应方法、结构及例子；正文继续按统一金融提示写作，不注入整份操作手册
