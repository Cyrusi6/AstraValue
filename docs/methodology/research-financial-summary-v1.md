# 历史增速与合并杜邦计算

本文件解释 `research-financial-summary-v1` 的可执行公式，不属于投资理论知识卡。

## 输入与公式

- CAGR：`(期末值/期初值)^(1/实际年度差)-1`。同指标、累计年度、主体、币种与单位一致，端点为正；五个年度观测通常只有四个间隔。结果不表示未来增长率。
- 平均资产：`(期初总资产+期末总资产)/2`。
- 平均总权益：`(期初总资产-期初总负债+期末总资产-期末总负债)/2`。
- 净利率：`合并净利润/营业收入`。
- 资产周转率：`营业收入/平均总资产`。
- 权益乘数：`平均总资产/平均总权益`。
- 合并权益收益率：上述三因子乘积，等于`合并净利润/平均总权益`。

合并净利润包含少数股东损益，分母采用包括少数股东权益的总权益。不与归母净利润、母公司权益或加权平均净资产收益率混用，也不将它解释为ROIC或WACC。

## 失败与追溯

缺期初余额则对应年份保持缺口；不以期末余额代替平均余额。收入、平均资产或平均权益不为正时不给出常规杜邦结果。不同主体/币种/单位拒绝混算。结果保存输入事实ID、公式版本、期间、值和适用边界；原始事实仍归原投影。

披露表整理另用 `filing-concentration-v1` 与 `filing-inventory-layout-v1`：前五名汇总按明确“万元/百分比”转换；存货只处理支持的四值或六值版式，核对减值与分类合计后才输出账面价值及组成比例。版式不满足时保留可读原文，不猜测空格对应零。账面存货不是渠道库存。

回归见 `tests/test_research_processing.py`，真实样本独立复算见 `tmp/moutai-processing-v1/independent-check.json`。此次只实际验收茅台；其他公司复用规则仍须验证自身输入与适用版式。
