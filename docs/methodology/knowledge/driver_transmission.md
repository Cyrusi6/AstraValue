# 驱动到利润现金估值的传导

本方法为 ES06.Q02 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 将驱动映射到收入，再沿单位成本、费用、税率和资本需求逐层传导，避免跳过中间变量。

2. 检查增长伴随的存货/应收和产能投资，利润增加可能暂时消耗现金；区分固定/可变成本的证据。

3. 在估值模型中保持现金流归属、增长、再投资和贴现口径一致，给单因素和组合场景而非直接价格目标。

## 输入、支持关系与缺失处理

所需证据：驱动基线、成本费用税率、资本开支/营运资本及模型定义。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

收入增长不必同比转化为现金流或价值，传导需把成本和再投资纳入；模型输出是条件化结果。

缺成本弹性或再投资变量时不给精确现金/估值传导，只列条件。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：新增经营收益20，但新增资本开支30、营运资本占款10，其他不变。 可说明增长消耗的现金可能超过收益贡献，需按完整模型计算。

反例：以收入增长10%直接令净利润、FCF和估值都增长10%。 省略利润率、再投资和贴现变化，不能支持该同比传导。

缺失例：缺成本弹性或再投资变量时不给精确现金/估值传导，只列条件。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
