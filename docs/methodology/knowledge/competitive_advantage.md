# 技术成本渠道品牌优势的证据链

本方法为 ES01.Q10 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 把技术、成本、渠道、品牌各主张改写为可观察机制：客户选择、可比单位成本、覆盖/替代约束或同条件溢价。

2. 分别取得产品性能/采用、同口径成本、渠道控制/库存责任及成交证据，核对竞品和替代解释。

3. 用优势兑现的利润/现金结果及反例检验持续性，记录复制、技术替代、合同到期和客户迁移的失效条件；定价权细读专门方法。

## 输入、支持关系与缺失处理

所需证据：技术和客户采用、可比成本、渠道合同、同条件价格及竞品证据。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

优势标签需由机制及兑现结果支持；转换成本、规模或品牌只有在实际改变客户/竞争选择时才构成有依据的优势路径。

某类优势缺关键证据时该主张标未知，不能用另一类优势材料代替。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：认证使客户切换需12个月，历史两次竞品替代失败，净成交和续单记录可核。 可支持观察期间存在切换约束，仍需跟踪认证变化与竞争者改进。

反例：广告强度高、知名度高且毛利高，但产品定位不同，缺可比价格及客户记录。 品牌线索不足以单独证明品牌溢价或不可复制优势。

缺失例：某类优势缺关键证据时该主张标未知，不能用另一类优势材料代替。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
