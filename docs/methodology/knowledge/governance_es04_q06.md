# 债券、转股与资本配置回报

适用于 ES04.Q06 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 提取发行净额、票息、付息到期、担保/排序、回售赎回和转股条件；区分公布条款与实际触发事件。
2. 把未来债务支付按合同时间排程，与现金、经营现金流和已承诺授信对照；未承诺再融资不能当确定来源。
3. 可转债分别讨论未转股、符合条件转股、回售/赎回的现金和股数变化，说明简化情景不等于正式稀释EPS。
4. 将筹资成本、投入时间、用途及形成的可归因现金回报联系起来；融资成功或EPS上升不自动证明资本配置创造价值。

## 必需证据及用途

- 债券募集说明/条款、余额、付息兑付及条件事件公告
- 转股价与实际转股、现金计划、资金用途及回报桥接

缺回售/赎回条件或转股价格，不能只凭票息估计总成本和稀释结果。

## 正常、反例与缺失

以下均为独立合成案例：

全额按固定价10转股的简化情景产生10股；是否会转、何时转及当期EPS仍需条件和时间口径。

票息低不能消除回售100与现金20的流动性缺口，需核查其他可用来源。

缺回售/赎回条件或转股价格，不能只凭票息估计总成本和稀释结果。

## 来源与边界

债务条款和违反契约的风险、资本配置实施以及权益稀释需分开评价。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF33/印刷31 §IV.A.10；PDF38/印刷36 §V.D.1；PDF19/印刷17 §II.C.5。

银行资本债、永续债、复杂嵌入期权及监管资本资格需要专用行业方法；不在此入口重复估值公式。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
