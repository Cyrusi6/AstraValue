# 审计、内控及整改记录

适用于 ES03.Q06 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 固定报告年度、审计对象、意见类型和强调事项/关键审计事项，财务审计与内控报告分别取证。
2. 追踪审计机构或项目人员变更、非审计服务和独立性披露；变更本身不等于财务舞弊。
3. 将监管问询、调查、处罚及整改通知分别列出发出日、责任主体、事项和最终结论，问询不直接写成违法定论。
4. 用整改措施、执行凭证及适当的复核/后续报告追踪关闭状态；回复函和整改计划不等于缺陷已消除。

## 必需证据及用途

- 审计/内控报告全文及意见对应事项
- 监管原文、整改措施、完成凭证和后续复核

只有整改承诺缺执行和复核材料，状态保持待核实，不写已闭环。

## 来源与边界

外部审计提供对报表的合理保证，管理层负报表责任；董事会需监督内控及报告体系。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF34/印刷32 §IV.C；PDF40/印刷38 §V.D.8。

审计标准、意见法律效果和监管程序依地区核对；不能从一个事项推断全部内控有效。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
