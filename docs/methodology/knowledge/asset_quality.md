# 资产质量、减值与可收回性

本方法为 ES02.Q05 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 按现金限制、应收账龄/信用、存货滞销和长期资产/商誉分别识别资产风险，不用同一减值模型覆盖所有资产。

2. 阅读适用会计政策、减值迹象、测试单元、估计现金流/贴现和准备变动，追踪本期计提、转回与处置。

3. 把账面余额和可收回证据联系起来，比较估计假设与经营实际；缺测试基础时列敏感因素而非擅自定量计提。

## 输入、支持关系与缺失处理

所需证据：资产构成、受限/账龄资料、减值政策及测试单元/假设。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

资产账面金额不自动等于可收回价值；IAS36概览明确多类资产另有减值标准，必须先确定适用范围。

缺账龄/测试假设或资产范围时仅列风险线索，不给无依据减值数。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：某设备账面100、同范围可收回额80，测试依据及计量条件已说明。 在该适用框架下可识别20的减值关系，同时记录现金流假设。

反例：把IAS36公式不加区别用于所有应收款和存货，或认为账面未减值就无信用风险。 资产类型及适用标准不同，未计提也不证明没有风险。

缺失例：缺账龄/测试假设或资产范围时仅列风险线索，不给无依据减值数。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
