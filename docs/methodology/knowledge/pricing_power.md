# 定价权：把可比价格、客户反应与利润联系起来

本方法帮助研究者检验定价权主张，不接收公司事实生成结论。`ES01.Q10` 的技术、成本、渠道与品牌其余路径见 `competitive_advantage.md`；本页专门核对定价权。

## 目标与适用条件

先确认产品、客户、地区、期间、渠道及实际成交条件可比较，再判断企业在竞争约束下提价的能力。适用于可以观察交易价格、成交数量与客户选择的产品或服务；银行利差、平台多边补贴、受监管公用事业价格等需要专用口径，不能直接套普通商品分析。没有行业或业务类型时，仅返回条件化指导。

## 执行顺序与输入

1. 固定比较单位。记录同规格产品、质量、服务、税费、币种、折扣返利及销售渠道。单位收入 `收入/销量` 是数量加权单位价值；高价产品、直营渠道或大批次的占比改变，都可能让它变化。只有各组成价格和数量可比时才进一步分离价格与结构效应。[IMF §§1.151–1.155]
2. 把调价公告与实际成交结果分开。按实施日期检查真实净成交价格、销量/订单、退款、折扣及终端或渠道反应。公告可证明意图，不能代替价格落实；产销统计要区分发给经销商与最终消费。[DOJ §4.1；渠道拆分是项目综合解释]
3. 检查提价后的收益与流失。销量略降并不自动否定定价权，应同时检查可比增量利润、客户流失及替代产品。不能把报表毛利率直接当作增量利润率；会计成本分类与经济增量成本可能不同。[DOJ §4.2.A、脚注72、§4.3.C]
4. 排除共同冲击与暂时因素。查看竞品价格、需求、原材料、税费、限产、促销和渠道库存；同时出现的成本通胀或供给中断不能自动归因为企业自身优势。选择同季或合理控制季节性的观察窗，短期事件与持续能力分别记述。[IMF §§1.168–1.170；DOJ §4.2.A；共同冲击检查为项目综合解释]
5. 追踪机制与失效条件。技术差异是否带来客户选择，转换成本是否实际阻碍迁移，规模是否降低可比成本，渠道是否难被竞争者复制，品牌溢价是否在同类比较中兑现。出现竞品替代、折扣增加、渠道积压或客户迁移时重新核验。[DOJ §§2.6.A、4.2.A]

关键原文输入包括价格实施日期与条款、销售口径、产品/渠道结构、客户转换及成本解释，必须保留文档、章节/页码、期间和支持的规则。可比净成交价、SKU销量、渠道库存和增量成本尚未证明与现有指标定义一一对应，当前全部标为 `pending`；不因有类似名称便宣称可直接取数。渠道库存并非所有直销业务的必要输入，先确认渠道模式，改用适合该模式的订单、留存或履约证据。

## 支持关系与反例

两种产品价格始终为100和200，销量从80/20变为20/80，总销量均为100，单位收入从120增至180。它证明销售结构改变；不能推出同品涨价。该合成案例直接来自单位价值恒等式，不是任何公司的事实。[IMF §1.154]

另一合成案例中，同品净价100升至110，销量100降至96，单位可变成本60不变，增量贡献由4,000升至4,800。若有客户迁移、替代品、促销与渠道正常的配套证据，可有限地支持“观察期间提价仍有利”；销量略降不能单独否决。它仍不能证明下一期可重复或永久护城河，增量贡献也不是完整会计利润。[DOJ §4.3.C，应用为项目综合解释]

若删掉实际成交、渠道或客户反应证据，只剩提价公告与混合单位收入，应列出待核查项，不能将充分证据案例的结论沿用。高毛利、品牌知名度、市场份额和研发金额都可以是线索，单独不足以证明持续定价权。5%的假想垄断者检验设定不是公司定价权评分门槛。[DOJ §4.1、§4.2.A脚注72、§4.3.B脚注84]
