# 并购出售、商誉及后续责任

适用于 ES04.Q05 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 分开交易意向、协议、批准、交割、控制取得/丧失与现金支付，确认被收购对象和合并范围变动日期。
2. 登记现金/股权/或有对价、承接债务、费用和少数权益口径，读取已披露购买价分摊；不能用支付现金简单等同总交易成本。
3. 追踪商誉形成、分配及减值披露，将溢价、协同假设与后续业绩分开；商誉大不直接等于未来必然减值。
4. 按合同追踪业绩承诺、补偿、担保、诉讼及出售保留责任；出售公告或收购完成均不自动证明后续义务消失。

## 必需证据及用途

- 交易协议、交割控制日期、对价和购买价分摊附注
- 商誉/减值测试披露、承诺补偿和后续现金履行

缺交割或价款分摊，只能陈述协议金额和状态，不编造合并日期或商誉。

在非同一控制、全资收购、对价及可辨认净资产均按公允价值且无既有持股等其他调整的简化前提下，商誉=120−100=20；真实交易须核对适用准则、少数权益和既有持股。

商誉20不能单独推出已经减值20，也不能证明协同已实现。

缺商誉/减值测试与后续履约证据时，保留已知协议及交易状态；不能判断是否减值、协同实现或后续责任解除，也不能用缺失值补零。
