# 价格、股本与估值分母口径

用于 ES05.Q01 的通用研究指导。这里的案例全部是合成教学数据；正文不陈述任何目标公司的事实。

## 分析目标与适用条件

在同一估值时点固定价格、股数与盈利期间；利润为零、负数或异常时停止把PE大小解释为正盈利企业的便宜程度。负分母仍可做算术，但不能沿用正盈利比较结论。

先核实业务性质、模型用途和所列口径；金融或行业专门路径按行业缺口处理。

## 输入与证据

- 估值日未复权成交价格与普通股股数；映射待补，先确认期间、单位与归属范围。
- 同归属口径的当期/TTM/预测盈利；映射待补，先确认期间、单位与归属范围。
- 债务、现金及其他非股权索偿桥接；映射待补，先确认期间、单位与归属范围。
- 关键输入、调整和假设的原文证据；需文档、页码及支持关系定位。

## 操作步骤

1. 标注价格日期、市场/币种、股本日期与普通股/摊薄选择，检查拆股、增发和回购是否已反映。
2. 分别列股权市值和企业价值，展示债务、现金、少数股权及其他索偿的桥接；不以市值替代企业价值。
3. 给盈利分母标记完整年度、TTM或预测期间，统一合并范围、归属范围和异常调整；检查零、负和极小分母。
4. 输出明确口径的倍数及待补项；无法核实股数/净债务/盈利归属时保留对应结果为空，并列所需原文。

## 公式与口径

合成恒定口径示例：股权市值=价格×对应股数；PE=股权市值/同归属盈利。此式不是完整稀释EPS会计规范。

## 依据与推导边界

来源直接支持：每股价格取决于股权价值和股份数量；当期、滚动与预测盈利对应不同PE口径，企业价值倍数与股权价值倍数应区分。
定位：SRC-NYU-VALUATION-SURVEY-2006@2006-11，PDF p59–60，Standardized Values and Multiples。

项目综合：在同一估值时点固定价格、股数与盈利期间；利润为零、负数或异常时停止把PE大小解释为正盈利企业的便宜程度。负分母仍可做算术，但不能沿用正盈利比较结论。
该综合的前提是原模型归属、现金流与风险口径一致。未把源文献未规定的软件和数据流程称为强制金融规则。

## 正常、反例与缺失案例

### normal — ES05.Q01.normal

合成输入：{"synthetic": true, "price_before": 20, "shares_before": 10, "profit": 10, "price_after_split": 10, "shares_after_split": 20}
可支持：拆股前后股权价值均200，同口径PE20。
不能支持：不能因拆股后价格减半断言便宜一半。

### counterexample — ES05.Q01.counterexample

合成输入：{"synthetic": true, "price": 20, "shares": 10, "profit": -10}
可支持：盈利为负，PE正盈利排序解释失效。
不能支持：不能因负PE小于正PE断言估值便宜。

### missing — ES05.Q01.missing

合成输入：{"synthetic": true, "price": 20, "shares": null, "profit_period": null}
可支持：须补股本日期与盈利期间。
不能支持：不能输出确定市值和PE。

## 主要限制和行业待补

- 历史复权价格不能与未调整股数机械相乘。
- 低倍数只是已定义分子与分母的关系，未证明风险、增长或现金流相同。
- 定量输入映射待补，不代表已能从事实库直接取数；方法不生成目标公司判断。
- 多类别股份、金融企业索偿和稀释工具的专门定义需行业/会计手册补充。
