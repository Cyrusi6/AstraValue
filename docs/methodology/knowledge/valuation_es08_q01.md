# 实际基线、假设与缺口分栏

用于 ES08.Q01 的通用研究指导。这里的案例全部是合成教学数据；正文不陈述任何目标公司的事实。

## 分析目标与适用条件

为可复现模型，将已披露实际、分析调整、预测假设和缺失分栏并记录时点；来源没有直接规定本项目的台账格式。

先核实业务性质、模型用途和所列口径；金融或行业专门路径按行业缺口处理。

## 输入与证据

- 带披露日期和期间的实际经营与资本数据；映射待补，先确认期间、单位与归属范围。
- 实际到调整后基线的逐项桥接；映射待补，先确认期间、单位与归属范围。
- 模型所需输入与缺口定位；映射待补，先确认期间、单位与归属范围。
- 关键输入、调整和假设的原文证据；需文档、页码及支持关系定位。

## 操作步骤

1. 冻结分析截止日，逐项列最近已披露实际、期间、单位、合并/归属范围与原文定位。
2. 将非经常项或口径统一写成可逆调整桥，不覆盖原披露值；把估计值单列为假设。
3. 按选定模型核查盈利、资本开支、折旧、营运资本、债务/股数是否齐备，解释每个缺口限制何种输出。
4. 输出基线表与待补表，保留缺失为空；只能使用已取得且口径一致的实际作为情景起点。

## 依据与推导边界

来源直接支持：模型首先依赖定义清楚的现金流归属、经营收益与再投资输入；企业和股权现金流不可混用。
定位：SRC-NYU-VALUATION-SURVEY-2006@2006-11，PDF p7–8、26，cash-flow claims and FCFF inputs。

项目综合：为可复现模型，将已披露实际、分析调整、预测假设和缺失分栏并记录时点；来源没有直接规定本项目的台账格式。
该综合的前提是原模型归属、现金流与风险口径一致。未把源文献未规定的软件和数据流程称为强制金融规则。

## 正常、反例与缺失案例

### normal — ES08.Q01.normal

合成输入：{"synthetic": true, "ebit": 120, "capex": 30, "depreciation": 10, "working_capital_change": 5, "all_disclosed": true}
可支持：可作为已定位的模型起点，但还要核对税率和模型条件。
不能支持：不能把已披露等同于没有会计估计风险。

### counterexample — ES08.Q01.counterexample

合成输入：{"synthetic": true, "actual_year": 2025, "forecast_year": 2026, "forecast_ebit": 120, "label": "actual"}
可支持：预测被错标为实际，必须分栏更正。
不能支持：不能声称实际利润已经达到120。

### missing — ES08.Q01.missing

合成输入：{"synthetic": true, "ebit": 120, "working_capital_change": null}
可支持：营运资本缺口限制FCFF计算。
不能支持：不能以零补齐营运资本变化。

## 主要限制和行业待补

- 当期尚未完整披露时不能把部分季度机械称为全年实际。
- 此处只规定核查步骤，不代表知识服务获取了公司数据。
- 定量输入映射待补，不代表已能从事实库直接取数；方法不生成目标公司判断。
- 行业业务量与监管资本基线的具体口径待行业手册补充。
