# 股权激励、摊销与潜在稀释

适用于 ES03.Q04 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 分清方案、批准、授予、归属/行权、失效和回购注销；员工持股与期权/限制性股票各自列示。
2. 提取授予数量、行权价、服务/业绩条件、有效期和修改；比较事前目标与实际达成，不能把批准等同授予或归属。
3. 从已披露股份支付费用和附注读取当期/未来摊销，解释估计、条件变化及现金/权益结算差别；不以股票市价乘数量替代费用。
4. 把最大新增股数的情景与实际加权平均股数、稀释EPS分开。说明资金来源、回购股份来源和是否新增发行，不能统一按新增股处理。

## 必需证据及用途

- 激励/持股方案及历次实施、变更和失效公告
- 股份支付附注、费用期间、股本来源及基本/稀释EPS口径

缺归属条件、费用注释或发行来源，不能给确定摊销或稀释EPS，只列待补参数。

## 正常、反例与缺失

以下均为独立合成案例：

若全部新发行且暂忽略其他股本变动，新股占发行后股本10%；这只是情景比例，并非当期稀释EPS。

批准上限10不能当成已归属10或当期摊销费用10。

缺归属条件、费用注释或发行来源，不能给确定摊销或稀释EPS，只列待补参数。

## 来源与边界

股权薪酬会影响激励和潜在稀释，需审阅条款、可度量长期目标及实质变更。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF19/印刷17 §II.C.5；PDF39/印刷37 §V.D.5。

具体股份支付计量遵从适用准则及披露，期权反稀释规则需单独核对；本路径不替代计算引擎。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
