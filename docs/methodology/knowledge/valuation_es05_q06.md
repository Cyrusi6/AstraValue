# 估值敏感性与稳健区间

用于 ES05.Q06 的通用研究指导。这里的案例全部是合成教学数据；正文不陈述任何目标公司的事实。

## 分析目标与适用条件

用有依据范围改变关键参数并单列口径变更；敏感性区间不是概率置信区间，g接近或超过折现率不能按正常终值解释。

先核实业务性质、模型用途和所列口径；金融或行业专门路径按行业缺口处理。

## 输入与证据

- 基准现金流、稳定增长与折现率；映射待补，先确认期间、单位与归属范围。
- 关键驱动参数的证据范围；映射待补，先确认期间、单位与归属范围。
- 各模型和会计口径调整；映射待补，先确认期间、单位与归属范围。
- 关键输入、调整和假设的原文证据；需文档、页码及支持关系定位。

## 操作步骤

1. 列基准模型、版本、各参数依据和最易改变估值的经营/融资变量，区分输入误差与模型选择差异。
2. 在相同经营假设下检查折现率×稳定增长的二维变化，禁止使用破坏稳定期条件的组合。
3. 再检查利润率、再投资和盈利口径改变，并用相对估值/DCF差异解释模型前提。
4. 报告主导敏感因素、仍支持的结论和失效条件；没有概率模型时称条件区间，不能称置信区间或保证回报。

## 依据与推导边界

来源直接支持：稳定增长估值对增长与资本成本敏感；倍数也隐含增长、风险和现金生成假设。
定位：SRC-NYU-VALUATION-SURVEY-2006@2006-11，PDF p27、62、65、73，stable growth and multiples。

项目综合：用有依据范围改变关键参数并单列口径变更；敏感性区间不是概率置信区间，g接近或超过折现率不能按正常终值解释。
该综合的前提是原模型归属、现金流与风险口径一致。未把源文献未规定的软件和数据流程称为强制金融规则。

## 正常、反例与缺失案例

### normal — ES05.Q06.normal

合成输入：{"synthetic": true, "next_fcff": 100, "growth": 0.03, "wacc_low": 0.1, "wacc_high": 0.12}
可支持：仅改变WACC，条件价值由约1428.57降至1111.11。
不能支持：不能把该区间当95%置信区间。

### counterexample — ES05.Q06.counterexample

合成输入：{"synthetic": true, "next_fcff": 100, "growth": 0.1, "wacc": 0.08}
可支持：不满足稳定增长求和条件，应退回模型设定。
不能支持：不能把负终值称为正常稳定期企业价值。

### missing — ES05.Q06.missing

合成输入：{"synthetic": true, "single_value": 1000, "parameter_ranges": null}
可支持：只给出点估值及待补参数范围。
不能支持：不能声称估值稳健。

## 主要限制和行业待补

- 逐项变化保持其他变量不变是局部敏感性，不能当真实联合情景。
- 稳定增长与资本成本过近时区间可能失去决策意义。
- 定量输入映射待补，不代表已能从事实库直接取数；方法不生成目标公司判断。
- 周期、金融和资源企业的相关参数范围需行业证据补充。
