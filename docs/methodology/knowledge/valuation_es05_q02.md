# 历史估值分布与时期变化

用于 ES05.Q02 的通用研究指导。这里的案例全部是合成教学数据；正文不陈述任何目标公司的事实。

## 分析目标与适用条件

历史分位必须冻结指标口径、窗口、采样频率和有效样本；描述样本内位置与判断低估分开。该复现步骤为项目综合。

先核实业务性质、模型用途和所列口径；金融或行业专门路径按行业缺口处理。

## 输入与证据

- 同口径历史倍数序列及采样日；映射待补，先确认期间、单位与归属范围。
- 各时点盈利期间和异常调整；映射待补，先确认期间、单位与归属范围。
- 窗口内增长、利率、资本结构变化；映射待补，先确认期间、单位与归属范围。
- 关键输入、调整和假设的原文证据；需文档、页码及支持关系定位。

## 操作步骤

1. 选定同一种倍数和盈利期间，记录窗口、每日/每月采样、交易日选择与缺失处理。
2. 复核拆股、会计准则、合并范围和一次性盈利变化；负盈利期间单列不可解释，不能删除后隐瞒样本变化。
3. 描述当前值在有效历史样本中的位置、样本数及剔除理由，同时比较增长、利率、风险与业务结构。
4. 至少给不同窗口或盈利正常化口径的敏感性；若口径无法统一，只展示并列序列和缺口，不输出唯一长期百分位。

## 依据与推导边界

来源直接支持：倍数分布会随时间变化；过去截面关系也会失去预测力，因此历史倍数需要对应当时基本面。
定位：SRC-NYU-VALUATION-SURVEY-2006@2006-11，PDF p59、73，Multiples / time-varying distributions。

项目综合：历史分位必须冻结指标口径、窗口、采样频率和有效样本；描述样本内位置与判断低估分开。该复现步骤为项目综合。
该综合的前提是原模型归属、现金流与风险口径一致。未把源文献未规定的软件和数据流程称为强制金融规则。

## 正常、反例与缺失案例

### normal — ES05.Q02.normal

合成输入：{"synthetic": true, "historical_pe": [10, 15, 20], "current_pe": 12, "same_basis": true}
可支持：可描述12位于本样本10与15之间；其余条件仍须核查。
不能支持：不能仅凭样本偏低推出低估。

### counterexample — ES05.Q02.counterexample

合成输入：{"synthetic": true, "old_growth": 0.2, "current_growth": 0.02, "old_pe": 25, "current_pe": 15}
可支持：增长结构改变可解释倍数中枢变化。
不能支持：不能断言回到旧25倍是合理价值。

### missing — ES05.Q02.missing

合成输入：{"synthetic": true, "history_pe": [10, null, 20], "period_basis": null}
可支持：历史口径待补，缺失值不置零。
不能支持：不能给声称完整的长期分位。

## 主要限制和行业待补

- 小样本分位容易随窗口大幅改变。
- 过去估值中枢不是永久合理价格，亏损期间缺失不应被当作零倍数。
- 定量输入映射待补，不代表已能从事实库直接取数；方法不生成目标公司判断。
- 周期企业正常化盈利、金融PB与资源净值历史口径尚需行业手册。
