# 催化剂、领先指标与失效条件

本方法为 ES06.Q05 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 为催化事项列最早/最晚窗口、必要审批/资源及下一可观察里程碑，区分预期与确定日期。

2. 为关键假设选有业务因果联系的领先指标，明确频率、来源、滞后和阈值依据，不能事后挑指标。

3. 预先列触发复查或撤销判断的条件，并跟踪数据修订及事件状态，未触发不等于假设得到证明。

## 输入、支持关系与缺失处理

所需证据：催化事件条款/进度、领先数据、阈值理由和假设版本。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

监测指标需有传导理由及时间关系；计划日和相关性不是必然兑现或股价反应保证。

缺里程碑或数据频率时记录监测缺口，不能制造定时完成承诺。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：订单必须验收后确认收入，下一季度合同约定验收且当前完成80%。 可把验收作为待跟踪催化并设置延迟复查条件，不能预认收入。

反例：股价上涨后挑选同时上涨指标，称它已被证明能领先预测。 事后相关并不确立领先或因果，需要预定规则和历史检验。

缺失例：缺里程碑或数据频率时记录监测缺口，不能制造定时完成承诺。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
