# 同行可比性与倍数差异

用于 ES05.Q03 的通用研究指导。这里的案例全部是合成教学数据；正文不陈述任何目标公司的事实。

## 分析目标与适用条件

先列匹配条件及不匹配项，再做条件化相对估值；没有足够信息调整差异时只报告倍数差异，不把差异全归为错价。

先核实业务性质、模型用途和所列口径；金融或行业专门路径按行业缺口处理。

## 输入与证据

- 同行与目标同口径倍数；映射待补，先确认期间、单位与归属范围。
- 增长、风险、再投资和现金生成能力；映射待补，先确认期间、单位与归属范围。
- 可比公司业务构成与财务调整原文；映射待补，先确认期间、单位与归属范围。
- 关键输入、调整和假设的原文证据；需文档、页码及支持关系定位。

## 操作步骤

1. 先按盈利模式、增长阶段、资本密集度和风险列候选集，记录纳入与排除理由。
2. 统一企业/股权分子、盈利/账面值分母、币种、时点和异常项目，确认负分母与金融行业限制。
3. 对照增长、现金转化、ROIC/再投资、杠杆及风险；逐项说明差异可影响倍数的方向。
4. 采用可解释的匹配子集、差异区间或有足够样本的调整模型；保留同业整体错价及模型误差，不机械取平均。

## 依据与推导边界

来源直接支持：可比企业的经济基础是现金流、增长潜力和风险相似；行业标签本身不构成充分可比依据。
定位：SRC-NYU-VALUATION-SURVEY-2006@2006-11，PDF p58、62、65，Comparable Firms。

项目综合：先列匹配条件及不匹配项，再做条件化相对估值；没有足够信息调整差异时只报告倍数差异，不把差异全归为错价。
该综合的前提是原模型归属、现金流与风险口径一致。未把源文献未规定的软件和数据流程称为强制金融规则。

## 正常、反例与缺失案例

### normal — ES05.Q03.normal

合成输入：{"synthetic": true, "growth_rates": [0.05, 0.05], "capital_costs": [0.1, 0.1], "cash_conversion": "similar"}
可支持：可纳入条件化比较，仍需确认其他口径。
不能支持：不能把近似可比称为完全相同。

### counterexample — ES05.Q03.counterexample

合成输入：{"synthetic": true, "industry": "same", "growth_rates": [0.02, 0.2], "capital_costs": [0.08, 0.15]}
可支持：同业但增长与风险明显不同，低倍数可有基本面解释。
不能支持：不能只因行业相同就判低倍数低估。

### missing — ES05.Q03.missing

合成输入：{"synthetic": true, "multiples": [12, 20], "peer_growth": null, "peer_risk": null}
可支持：可保留原始倍数差异，补增长与风险后再解释。
不能支持：不能直接输出相对低估幅度。

## 主要限制和行业待补

- 回归相关性不能替代经济解释，样本少和共线性会削弱调整。
- 相对估值依赖市场平均定价，不证明内在价值。
- 定量输入映射待补，不代表已能从事实库直接取数；方法不生成目标公司判断。
- 行业专属风险指标和跨市场会计调整需进一步定义。
