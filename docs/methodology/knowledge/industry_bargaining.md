# 产业链价格成本传导与议价

本方法为 ES07.Q05 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 选择对应交易环节的净价格、原料/能源/人工成本与合同指数，明确频率、滞后和权重。

2. 用同品/同质量序列检查成本变化如何传到成交价、毛利和库存，区分即时、滞后和未传导。

3. 结合上下游替代、合同重定价、集中及转换成本解释议价，结构变化或供需共同冲击不得都归给品牌。

## 输入、支持关系与缺失处理

所需证据：可比价格成本指数、合同重定价条款、库存及替代选择。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

传导关系要用相同链条和时间约定验证；相关价格同时上涨不证明某企业拥有独立提价权。

缺实际成交或成本权重时只比较方向，不能精确计算成本转嫁率。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：合同价格按原料指数滞后一季调整，本季原料涨、下季成交价才涨。 可检验约定的滞后传导，不能把本季毛利压缩直接视为永久失权。

反例：全行业商品价格随供给短缺上涨，单家公司均价同步上涨即称品牌强。 共同供需冲击是替代解释，需要公司差异化证据。

缺失例：缺实际成交或成本权重时只比较方向，不能精确计算成本转嫁率。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
