# 股权、表决权与实际控制

适用于 ES03.Q01 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 固定公告截至日与股份类别，列直接持股、间接路径和最终实益拥有人；同一股份沿链条追踪，不重复相加。
2. 将经济权益、表决权、董事任免和协议安排分别列示；持股比例相同不能自动认定控制权相同。
3. 将控制人认定与最新章程、表决权委托、一致行动或终止文件核对；不能只由最大股东排名认定实际控制。
4. 比较报告期及最新事件后的关系图，标记有效日期、冲突披露和待核实链条；结论写明采用哪一时点。

## 必需证据及用途

- 股东名册、总股本、类别及截至日
- 控制链、协议有效期、表决权委托及董事任免说明

缺中间控股实体和表决权协议，只能列已知持股，不能补出最终控制人。

## 正常、反例与缺失

以下均为独立合成案例：

有效委托使披露口径下表决权55%高于经济持股30%，两种权益必须分别列示。

仅知持股最多25%，不足以认定实际控制人。

缺中间控股实体和表决权协议，只能列已知持股，不能补出最终控制人。

## 来源与边界

资本及集团结构、控制安排和实益所有人应一并披露，持股表不等于控制关系图。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF30–31/印刷28–29 §IV.A.3–4。

少数持股、共同控制、金字塔结构和特殊表决权需解释具体协议；不能套统一控股比例。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
