# 收入利润增长与非经常因素

本方法为 ES02.Q02 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 先统一可比期间和范围，再分别计算收入、经营利润、归母利润等明确指标的变化。

2. 从附注区分业务增长、并购/汇率、处置收益、补助、减值和其他非经常影响，逐项核税与归属。

3. 同时保留报告值与有依据的调整值；亏损转盈利或极小基数用金额桥接，不用百分比制造稳定增长印象。

## 输入、支持关系与缺失处理

所需证据：利润分项、非经常项目性质、税额/归属和合并范围桥接。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

重大利润变化需要说明驱动；调整必须保留原披露及项目证据，不能因不喜欢波动任意剔除经常成本。

缺项目税额或归属时不精确给归母调整利润，只给已知影响范围。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：报告利润由10到30，其中本期处置收益15、其他口径相同。 可说明报告增加20，其中处置贡献15，剩余变动仍需经营证据。

反例：上年亏损1、本年盈利1，被描述为稳定增长200%。 符号切换下该比例不代表稳定增长，应报告扭亏金额及原因。

缺失例：缺项目税额或归属时不精确给归母调整利润，只给已知影响范围。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
