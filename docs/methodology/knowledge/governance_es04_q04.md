# 融资进度与募集资金用途

适用于 ES04.Q04 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 建立融资决议、审批/注册、发行、到账、扣费净额和项目投入时间线；授权额度不视为已获得资金。
2. 将募集总额、费用、净额、使用金额和期末余额按专户/项目对账，区分利息、现金管理、暂时补流和永久用途变更。
3. 将每项资金用途与项目预算、工程进度、产能形成和经营收益相连；花完资金不等于产能投产或投资回报达标。
4. 追踪延期、终止、变更批准及实施，保留原承诺与修订版本；缺资金流或项目材料时列差额待查。

## 必需证据及用途

- 融资方案、发行到账净额与募集资金专项报告
- 项目预算、实际使用/余额、用途变更与产出证据

缺专项使用报告或到账净额，不能按批准额度倒算余额，也不能判断资金被挪用。

## 正常、反例与缺失

以下均为独立合成案例：

净募集98与已使用60、余额38相符；只确认资金去向勾稽，项目收益仍需独立证据。

注册或批准上限100不等于已募得100。

缺专项使用报告或到账净额，不能按批准额度倒算余额，也不能判断资金被挪用。

## 来源与边界

新增股份、资本结构和重大项目实施需要可理解的信息与实施监督。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF17/印刷15 §II.B；PDF30/印刷28 §IV.A.3；PDF38/印刷36 §V.D.1。

募集专户、用途变更程序和各市场融资安排按具体规则补充；会计差额需要考虑外币及跨期。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
