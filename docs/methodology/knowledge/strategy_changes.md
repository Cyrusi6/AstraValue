# 战略变化的目标、执行与结果

本方法为 ES01.Q09 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 给战略、资产出售、并购、新业务和组织变动建立公告/生效/执行时间线。

2. 逐项列目标、资源承诺、实际投入、里程碑与责任人，经营范围变化与口号分开。

3. 比较可观察结果与原目标，检查延迟、取消、成本上升和反证，再判断哪些变化影响后续基线。

## 输入、支持关系与缺失处理

所需证据：战略公告、董事会计划、资本支出/项目进度及实际经营结果。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

目标、实施和结果是不同证据状态；更新战略不能反过来篡改原目标及历史实际。

缺基期目标或里程碑时保留判断范围，先补历史披露。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：两年前计划新厂，现已投产但产量仅达目标一半，成本高于预算。 可分别确认投产完成及爬坡/成本偏差，不能简单称战略全部成功。

反例：年报提出进入新市场，未披露投入或交付，后续未见进展。 只能记录战略意图，不能将计划收入作为实际基线。

缺失例：缺基期目标或里程碑时保留判断范围，先补历史披露。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
