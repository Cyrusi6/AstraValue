# 产能、产销存与投产进度

本方法为 ES01.Q05 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 定义有效产能及期间，区分设计、已建、在建、试生产与可销售产能；检查停工、季节和产品转换。

2. 以同产品同单位核产量、销量、库存与外购/损耗/范围变动桥接；不能把全部差额认作库存。

3. 产能利用率仅在实际产量和可用产能范围一致时解释，再联系订单、价格、库存账龄及投产时间。

## 输入、支持关系与缺失处理

所需证据：产量/销量/存货数量、有效产能定义、在建项目状态及桥接项。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

目标产能和实际可用能力必须区分；产销存及利用率是明确期间和范围后的关系，不是项目公告自动实现。

缺有效产能定义或外购/损耗时保留桥接差异，不输出精确利用率。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：年初库存10、生产100、销售90、无其他流入流出，则期末库存20；有效产能125。 可在完整简化条件下核库存20和利用率80%，并检查库存增长原因。

反例：公告规划产能200，当前仅100完工，全年产量80。 不能用规划200把利用率算成40%，应先确认有效产能和投产月份。

缺失例：缺有效产能定义或外购/损耗时保留桥接差异，不输出精确利用率。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
