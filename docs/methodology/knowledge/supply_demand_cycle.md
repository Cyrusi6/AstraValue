# 供需产能库存的通用变量选择

本方法为 ES07.Q03 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 按行业交易模式选需求、供给、有效产能、投产时点和库存变量，明确每项是流量还是存量。

2. 统一范围与期间，核产销存桥接和产业链库存位置；项目规划、已建与可用供给分开。

3. 观察需求、产能爬坡、开工、价格和库存的联合变化及替代解释，不能由单一库存方向断言周期拐点。

## 输入、支持关系与缺失处理

所需证据：需求/订单、产销、有效产能和投产时间、分层库存及价格。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

供需判断必须把可用供给、需求和存货位置联系起来；同方向库存变化可能由不同机制产生。

缺库存位置或有效产能时列替代情景，不给单一周期结论。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：终端需求上升、库存下降且价格稳定，既有产能利用率同步提升。 可把需求吸收库存作为受支持解释之一，仍检验补库和供给限制。

反例：渠道去库存但生产商库存上升，单看渠道库存下降称全行业景气上行。 库存可能在链条转移，不能用一层库存替代整体供需。

缺失例：缺库存位置或有效产能时列替代情景，不给单一周期结论。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
