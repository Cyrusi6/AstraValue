# 关联交易、条款与承诺履行

适用于 ES03.Q05 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 按当期关联关系与交易主体识别交易和余额，区分往来、担保、资金占用及未执行承诺，不将同集团名称当充分关系证据。
2. 将金额、定价条款、结算期限和第三方参照比较；审批与回避只证明程序部分，公平性需可比条件和实际履行支持。
3. 为每项承诺登记义务人、受益人、触发条件、到期日、应履行与已履行数量；将续期或修改另列，不能覆盖原到期事实。
4. 把交易批准、合同生效、交付、付款、逾期和整改分开；无履行证据标未知，已有到期未付款证据才指出相应未履行。

## 必需证据及用途

- 关联关系、交易批准与合同定价结算条款
- 履行凭证、到期条件、余额及承诺变更记录

只有审批公告缺合同和履行凭证时，履行状态未知，不能默认完成或擅自认定利益输送。

## 正常、反例与缺失

以下均为独立合成案例：

在约定范围内到期款100已按期收到，可支持该项已履行；不外推全部关联交易公平。

审批存在但到期100未收，应记录此项未履行，不能称承诺完成。

只有审批公告缺合同和履行凭证时，履行状态未知，不能默认完成或擅自认定利益输送。

## 来源与边界

关联交易须识别利益冲突、金额、条款及治理处理；关联本身不必然不当，审批不能替代实质判断。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF21/印刷19 §II.F.1；PDF32/印刷30 §IV.A.7；PDF40/印刷38 §V.D.7。

关联方定义、豁免与审批门槛依适用制度核对；跨境和金融关联交易需要行业补充。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
