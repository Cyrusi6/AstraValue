# 企业倍数、分部估值与行业路径

用于 ES05.Q05 的通用研究指导。这里的案例全部是合成教学数据；正文不陈述任何目标公司的事实。

## 分析目标与适用条件

分部估值必须逐部统一对象和输入，再扣未分摊费用、共享资产及重复项并做股权桥接；这是现金流现值可加性的项目应用，不是综述提供的现成分部模板。

先核实业务性质、模型用途和所列口径；金融或行业专门路径按行业缺口处理。

## 输入与证据

- EV桥接、EBITDA及异常调整；映射待补，先确认期间、单位与归属范围。
- 分部现金流、资本开支和共同费用；映射待补，先确认期间、单位与归属范围。
- 债务、现金、共享资产和少数权益归属；映射待补，先确认期间、单位与归属范围。
- 关键输入、调整和假设的原文证据；需文档、页码及支持关系定位。

## 操作步骤

1. 选择EV/EBITDA前核对企业价值桥接和EBITDA调整，检查税、维护资本开支和营运资本需求。
2. 为每个分部记录业务范围、利润/现金流、资本需求及可比对象；公司收入分部不能直接替代利润分部。
3. 对可独立估值分部采用一致模型，合并共享成本、债务、非经营资产和少数权益，明确未分摊和抵销项目。
4. 遇银行、保险等企业先返回普通企业倍数的不适用条件，说明应补行业股权/监管资本模型；不以空行业模型冒充完成。

## 依据与推导边界

来源直接支持：EBITDA等倍数仍受再投资、增长与资本成本影响；行业专属倍数若难以联系盈利和现金流，可能掩盖整个行业错价。
定位：SRC-NYU-VALUATION-SURVEY-2006@2006-11，PDF p26、61、65，FCFF / sector multiples / determinants。

项目综合：分部估值必须逐部统一对象和输入，再扣未分摊费用、共享资产及重复项并做股权桥接；这是现金流现值可加性的项目应用，不是综述提供的现成分部模板。
该综合的前提是原模型归属、现金流与风险口径一致。未把源文献未规定的软件和数据流程称为强制金融规则。

## 正常、反例与缺失案例

### normal — ES05.Q05.normal

合成输入：{"synthetic": true, "segments": ["A", "B"], "operating_values": [100, 150], "shared_cost_value": 20, "non_equity_claims": 30}
可支持：在无重复项且分部值口径一致的假设下，可桥接经营价值230及股权200。
不能支持：不能忽略共同成本与非股权索偿。

### counterexample — ES05.Q05.counterexample

合成输入：{"synthetic": true, "ebitda": [100, 100], "maintenance_capex": [10, 80], "ev": [500, 500]}
可支持：相同EV/EBITDA并不意味着现金创造能力相同。
不能支持：不能将EV/EBITDA无条件用于所有业务。

### missing — ES05.Q05.missing

合成输入：{"synthetic": true, "segment_revenue": [100, 200], "segment_ebitda": null, "shared_costs": null}
可支持：须补分部盈利/再投资及共同项目；可保留模型框架。
不能支持：不能按收入占比生成精确分部利润和估值。

## 主要限制和行业待补

- EBITDA不扣资本消耗，不能代替自由现金流。
- 分部信息缺失时分部合计只能是条件区间，不能把收入比例当利润权重。
- 定量输入映射待补，不代表已能从事实库直接取数；方法不生成目标公司判断。
- 银行/保险、资源储量、REIT和其他行业专用估值仍需行业定义与案例。
