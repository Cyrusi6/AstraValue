# 表外责任、会计变更与异常核对

本方法为 ES02.Q10 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 扫描担保、诉讼、承诺、或有事项、非现金交易及特殊目的主体，记录义务对象、金额、条件和状态。

2. 区分已确认准备、披露的或有负债和仅管理层计划；未入表不能等于零风险。

3. 分别处理政策变更、估计更新和差错更正，保存原版与重述桥接，异常指标回到原表和附注核实。

## 输入、支持关系与缺失处理

所需证据：或有事项/承诺、会计变更和重述附注及原始财务版本。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

未入表可能仍有披露义务或风险；政策、估计与差错有不同性质，异常只能先作为核查信号。

缺合同/进展或无法区分变更性质时保留未知，不能自行确认会计金额。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：诉讼结果尚不确定，附注披露可能义务；另有折旧寿命因新信息调整。 可分别记录或有风险和估计变化，不把后者称作前期造假。

反例：表内负债未列诉讼金额，于是把附注披露的担保风险记零。 表内缺项不证明无义务，须保留触发条件与范围。

缺失例：缺合同/进展或无法区分变更性质时保留未知，不能自行确认会计金额。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
