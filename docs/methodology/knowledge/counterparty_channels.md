# 客户供应商与渠道依赖

本方法为 ES01.Q03 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 分别列主要客户、供应商及渠道，核对合并口径和集中度分母；匿名披露保持匿名。

2. 区分收入/采购占比和真正依赖：合同期限、切换成本、可替代性、付款条件和交易方向需另取证。

3. 联系应收、库存、价格条款及终端需求，检查客户依赖是否转化为风险暴露，避免从集中度一项直接判强弱。

## 输入、支持关系与缺失处理

所需证据：客户供应商身份/匿名分项、销售采购分母、合同渠道和可替代证据。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

集中比例是依赖线索；客户替代和交易条款决定它如何影响议价与风险，匿名项不能补造名称。

缺采购分母或渠道模式时不算可比集中度、不推断库存归属。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：前五客户占30%，其中客户X有到期合同且可在三个月更换，余项身份不公开。 可报告30%销售集中及X合同事实，匿名客户保持未知。

反例：前五供应商占80%，但原料标准化且存在已验证替代供方。 不能仅凭80%认定供应商不可替代，须判断切换成本与交付。

缺失例：缺采购分母或渠道模式时不算可比集中度、不推断库存归属。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
