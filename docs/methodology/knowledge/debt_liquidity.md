# 债务到期与现金可用性

本方法为 ES02.Q06 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 逐项列有息债务、租赁、担保及到期安排，核本息币种、利率、抵押和交叉违约条款。

2. 现金可用性按受限、地域、主体与用途核对，经营现金、已承诺授信和拟融资分开。

3. 用期限匹配的现金来源/支出与契约压力场景判断偿付暴露；未知债务组成不能称完整净债务。

## 输入、支持关系与缺失处理

所需证据：借债/租赁到期表、现金限制、利率担保契约及已承诺授信。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

偿债能力不仅取决于总量，还取决于期限、可用现金和契约；拟融资不能当已取得现金。

缺到期表或现金限制时不输出完整流动性安全结论。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：半年内到期债务50、同主体可用现金30、已承诺可提款额度25，条件已满足。 可做55对50的近期资金匹配，但仍须列经营资金需求和提款条款。

反例：账面现金100但其中90受限，近期到期债务50，称现金覆盖两倍。 受限现金不可无条件用于偿付，可用覆盖不能按100计算。

缺失例：缺到期表或现金限制时不输出完整流动性安全结论。
