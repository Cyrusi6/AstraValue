# 回购执行、用途和注销

适用于 ES04.Q02 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 登记回购目的、期限、额度、价格约束与资金来源；将方案上限、已购买、已注销分别记录。
2. 以实施进展与成交记录核查实际金额、股数及平均成本，剔除重复累计报告；币种、日期和费用口径一致。
3. 按注销、股权激励、员工持股、库存用途追踪股份最终流向；购买完成不代表总股本已经减少。
4. 评价每股影响时结合发行/激励新增股数、付款现金和回购价格区间；回购或EPS机械上升不能独立证明价值创造。

## 必需证据及用途

- 回购方案及按期进度、累计成交数量金额
- 用途变更、股份过户/注销凭证和同期股本桥接

缺成交数量、用途或注销状态，分别留缺，不用公告额度补成交或直接假设注销。

## 正常、反例与缺失

以下均为独立合成案例：

确认已回购10股、支付100，尚未注销且用途为员工计划，不能减少期末总股本10。

有上限100而成交为零，仅为计划，不能称完成回购。

缺成交数量、用途或注销状态，分别留缺，不用公告额度补成交或直接假设注销。

## 来源与边界

重大资本安排与实施应有清楚信息；回购状态划分是本项目依据实施证据建立的方法。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF17/印刷15 §II.B；PDF38/印刷36 §V.D.1。

股份注销程序、库存股及EPS处理按适用会计和法律核验；本页不提供统一回购估值结论。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
