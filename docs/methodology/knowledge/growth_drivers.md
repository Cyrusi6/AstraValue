# 增长驱动的可观察变量

本方法为 ES06.Q01 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 从收入结构选销量、净价、份额、客户数、渗透率或新业务交付等与收费机制相符的变量。

2. 把同产品价格/数量与结构、并购、汇率分开；每个变量给基线、期间和证据定位。

3. 连接产能/客户/合同约束并核领先信号，计划与已交付分别标记，不能把所有宏观增长直接归公司。

## 输入、支持关系与缺失处理

所需证据：分产品量价/结构、订单交付、行业分母与业务约束。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

增长驱动应能解释收入变化并有业务传导路径；指标变化和未来计划不自动成为公司已实现增长。

缺销量/结构或新业务交付时只列候选驱动和待验证变量。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：同品价格不变，实际销量上升20%，范围稳定，交付和收入可核。 可支持数量贡献的历史增长解释，未来增速仍要检查约束。

反例：行业规模增20%，公司份额和交付均未知，直接预测公司也增20%。 行业增速不能替代公司份额与履约证据。

缺失例：缺销量/结构或新业务交付时只列候选驱动和待验证变量。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
