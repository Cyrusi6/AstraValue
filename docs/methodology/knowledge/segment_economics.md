# 产品地区渠道的收入与利润结构

本方法为 ES01.Q02 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 按披露的产品、地域、渠道分类建同期间同范围表，记录分类调整与内部交易抵销。

2. 分别核收入、成本和利润定义；分部利润、毛利、营业利润、净利润不要互换，未分摊成本单列。

3. 计算结构占比时明确分母并检查分项加总；只披露收入时停留在收入结构，不能推利润贡献。

## 输入、支持关系与缺失处理

所需证据：分部收入/成本/利润定义、分摊及抵销附注。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

不同业务和经济环境的信息应分别解释；收入占比不是利润占比，分类和抵销须可比。

缺成本分摊或抵销，只列已披露指标并保留利润贡献缺口。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：分部A/B收入60/40，毛利12/20，分部定义与抵销完整。 可分别描述A贡献60%收入、B贡献更大毛利，不能称净利润贡献。

反例：仅有A收入占60%，没有分部成本或利润。 收入比例不足以判断A贡献60%利润。

缺失例：缺成本分摊或抵销，只列已披露指标并保留利润贡献缺口。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
