# 股东增减持、锁定与解禁

适用于 ES04.Q03 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 按主体关联关系、股份类别和有效日期整理计划、实际成交、过户与终止，区分公司回购和股东个人交易。
2. 按股数和持股分母桥接期初期末持股，考虑拆股、增发和转让；不直接累加滚动累计公告。
3. 登记锁定起止、可流通条件、预计解禁和实际解除数量；解禁只增加可交易集合，不等于已卖出。
4. 结合计划原因、实际资金和控制安排记录可观察变化；不由高管增持直接推出低估，也不由减持直接推出经营恶化。

## 必需证据及用途

- 计划与实际成交/过户、持股分母和主体关系
- 锁定约束、条件满足与实际解除公告

只有减持计划或解禁日历而无实施记录，实际成交未知，不能估算实际资金流出。

## 正常、反例与缺失

以下均为独立合成案例：

同口径持股30减实际出售5为25，可确认减持数量，不能单凭此判断盈利趋势。

解禁20但无成交，不能计为已经减持20。

只有减持计划或解禁日历而无实施记录，实际成交未知，不能估算实际资金流出。

## 来源与边界

重要所有权及控制变化、管理人员持股交易安排是需观察的治理信息。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF30–31/印刷28–29 §IV.A.3–4；PDF39/印刷37 §V.D.5。

当地交易窗口、豁免和锁定规则需核对最新正式文件，不从治理原则推定具体期限。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
