# 三表范围与历史可比桥接

本方法为 ES02.Q01 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 核审计状态、会计基础、母公司/合并、币种单位、报告期以及是否重述，三表保持同一范围。

2. 逐年列合并范围、终止经营、会计政策/估计和差错更正，优先使用有解释的可比重述数据。

3. 建立原披露到调整后比较口径的桥接；无法统一的期间分别呈现，不能无说明计算连续增速。

## 输入、支持关系与缺失处理

所需证据：报表表头、审计意见、合并范围、重述及会计政策/估计附注。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

报表可比性由主体、期间、单位和会计基础共同决定；政策、估计、差错更正不能混成同一种变动。

缺合并范围或重述说明时不把历史序列标为完全可比。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：两年均同币种同范围，比较数因差错正式重述且附有调节。 可使用重述后可比序列并保留原版本和更正说明。

反例：本年新增并购主体占收入一半，上年数字未含它，却直接称有机收入翻倍。 合并范围变化破坏有机增长解释，须桥接或留缺。

缺失例：缺合并范围或重述说明时不把历史序列标为完全可比。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
