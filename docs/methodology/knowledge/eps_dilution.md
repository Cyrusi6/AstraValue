# 每股收益的股数与潜在稀释

本方法为 ES02.Q09 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 先取基本/稀释EPS披露及分子归属，确认普通权益持有人收益，不把合并总利润直接代入。

2. 核加权平均股数、送转拆并、发行回购时点及持续/终止经营；期末股数与加权分母明确分开。

3. 查可转债、期权、限制性股等潜在普通股及未纳入原因，分别记录报告EPS和条件化稀释场景。

## 输入、支持关系与缺失处理

所需证据：基本/稀释EPS分子分母调节、股本时间线及潜在股份条款。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

期间EPS需要与收益归属相符的加权平均普通股，期末总股本不能静默替代；潜在稀释有条件。

缺股数时点、分子归属或转股条款时只用已披露EPS，情景另留缺。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：归属普通股收益100，半年股数100、半年200，则加权150。 基本EPS可在简化同口径下为100/150，而非100/200。

反例：年末增发100股后总股本200，用200计算整年EPS且称与报告完全一致。 期末股数不反映整年加权，需按发生时点及披露调节。

缺失例：缺股数时点、分子归属或转股条款时只用已披露EPS，情景另留缺。
