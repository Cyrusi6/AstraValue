# 产业链位置与交易议价

本方法为 ES01.Q08 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 按采购、生产/服务、分销到终端客户识别公司承担的环节、资产和风险，不按行业名称猜位置。

2. 核上游替代供给、下游替代产品、转换成本与合同结算，分别检查供应与客户议价。

3. 用价格/成本传导、账期和库存责任验证议价机制，内部关联流转与外部市场交易分开。

## 输入、支持关系与缺失处理

所需证据：合同和价值链流程、替代选择、价格/成本传导及账期。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

上下游地位由实际交易环节和双方替代选择约束；所在环节和规模本身不能证明强议价。

缺合同、采购替代或结算条款时只标环节，议价结论留缺。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：企业承担设计销售、外包制造，有两家可替代代工厂，客户切换认证需一年。 可描述资产与客户认证的作用机制，强度仍需成交及迁移验证。

反例：公司被称为行业龙头，但核心材料独家供应且涨价无法向客户传递。 龙头标签不消除上游依赖，不能直接判全链条强议价。

缺失例：缺合同、采购替代或结算条款时只标环节，议价结论留缺。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
