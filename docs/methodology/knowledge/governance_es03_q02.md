# 质押、冻结与控制稳定性

适用于 ES03.Q02 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 分别登记出质人、质权人、股份数量、开始/到期、解除/冻结及处置公告；按同一股份和时点去重。
2. 分别计算质押占该股东持股和占公司总股本的比例，说明分母日期；不能把两种比例混用。
3. 检查补充担保、偿付安排、司法处置与表决权约定；只有实际触发和处置证据才讨论控制变动。
4. 按已质押、到期临近、发生违约、正在处置、已过户区分事实，缺合同阈值时不推算强平价格。

## 必需证据及用途

- 股东及公司同日持股分母、质押解除冻结明细
- 合同或公告中的触发条件、补担保和执行状态

缺触发条款与偿付能力证据，能记录质押余额，不能预测强平价或失控日期。

## 正常、反例与缺失

以下均为独立合成案例：

同日质押占股东50%、占公司20%，仅描述暴露，不自动证明违约。

高质押暴露不等于违约或控制权已转移。

缺触发条款与偿付能力证据，能记录质押余额，不能预测强平价或失控日期。

## 来源与边界

控制安排与公司具体风险、债务契约需结合审阅；项目据此将质押及处置事件分阶段组织。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF30–33/印刷28–31 §IV.A.3–4、IV.A.8–10。

股份类别、当地担保法和司法程序需要具体文件；OECD未规定质押强平阈值。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
