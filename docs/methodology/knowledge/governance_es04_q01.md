# 现金分红政策与实际回报

适用于 ES04.Q01 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 分开列政策、董事会提案、股东通过、权益登记与实际支付；特别分红与常规分红区分。
2. 统一每股税前/税后、币种、股本基数与期间，确认总额和每股金额可桥接；股息率标明使用哪一天股价。
3. 将股利与相同利润归属范围、可用现金及投资偿债需要比较；亏损或一次性利润下分红比例可能不可解释。
4. 从支付记录核查实际股东回报，分清分红、回购和融资流入；高股息率须排除价格暴跌、特殊分红和未支付提案。

## 必需证据及用途

- 政策、批准及实际派息公告、股本基数和税费口径
- 可比利润、现金流、债务与投资需求

缺付款状态或同口径利润，只报告政策/提案及缺项，不给已实现分红比例。

## 正常、反例与缺失

以下均为独立合成案例：

同范围普通现金派息20/利润100=20%的已支付比例；不证明未来可持续。

提案20不等于股东已收20，预期股息率须标注未实施。

缺付款状态或同口径利润，只报告政策/提案及缺项，不给已实现分红比例。

## 来源与边界

股东有分享利润与获取信息的权利，资本配置需结合公司战略、预算和实际实施审阅。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF17/印刷15 §II.A；PDF38/印刷36 §V.D.1。

特定地区可分配利润规则、银行监管资本限制及税负需要另行取证，不预设统一分红比例。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
