# 资本开支周期与投产约束

本方法为 ES01.Q06 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 按项目列承诺投资、实际现金支出、在建余额与转固/投产日期，区别计划、执行及会计余额。

2. 识别维护、扩张、研发经济再投资和并购；维护/扩张未披露时不自行精确分摊。

3. 将投产爬坡、折旧、产能与收入兑现相连，结合多年资本开支判断周期，不能把低开支一年永久化。

## 输入、支持关系与缺失处理

所需证据：项目预算/实际支出、在建与转固、折旧、产能及收入兑现证据。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

再投资可能成块发生，现金支出与投产收益有时差；计划金额不是已付资本开支。

缺维护/扩张分解时保留总支出与区间情景，不造维护开支数。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：项目预算100、累计支付40、在建30，预计次年投产且尚未贡献产量。 可判项目仍建设中，分别报告预算、付款与资产余额。

反例：本年购建现金支出骤降，但大项目去年刚完工，未来仍需维护。 不能由本年低支出直接推断永久高自由现金流或停止投资。

缺失例：缺维护/扩张分解时保留总支出与区间情景，不造维护开支数。
