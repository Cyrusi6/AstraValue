# 结论证据、估值折价与失效条件

用于 ES08.Q04 的通用研究指导。这里的案例全部是合成教学数据；正文不陈述任何目标公司的事实。

## 分析目标与适用条件

把安全边际表述为相对明确估值区间、假设和证据的价格折价，并列改变结论的条件；不把折价当收益保证或统一比例规则。

先核实业务性质、模型用途和所列口径；金融或行业专门路径按行业缺口处理。

## 输入与证据

- 同口径市场价格与估值区间；映射待补，先确认期间、单位与归属范围。
- 主要经营证据和关键假设；映射待补，先确认期间、单位与归属范围。
- 反例、敏感参数及结论失效条件；映射待补，先确认期间、单位与归属范围。
- 关键输入、调整和假设的原文证据；需文档、页码及支持关系定位。

## 操作步骤

1. 将结论拆为已确认事实、条件推断、关键假设与尚缺证据，逐条说明支持关系。
2. 以相同每股/股权口径比较市场价格与多个合理假设下的估值区间，说明模型分歧由什么驱动。
3. 核对最重要反例：利润正常化失败、竞争恶化、资本需求增加或同行整体错价，记录会推翻判断的条件。
4. 报告支持范围、价格折价区间和脆弱参数；关键证据不足时缩窄结论，不凭模型输出制造确定买卖结论。

## 依据与推导边界

来源直接支持：内在价值不可直接观测；相对估值与DCF可能相反，同业整体高估时相对便宜不保证低于内在价值。
定位：SRC-NYU-VALUATION-SURVEY-2006@2006-11，PDF p6、73–74，intrinsic value uncertainty and model reconciliation。

项目综合：把安全边际表述为相对明确估值区间、假设和证据的价格折价，并列改变结论的条件；不把折价当收益保证或统一比例规则。
该综合的前提是原模型归属、现金流与风险口径一致。未把源文献未规定的软件和数据流程称为强制金融规则。

## 正常、反例与缺失案例

### normal — ES08.Q04.normal

合成输入：{"synthetic": true, "price": 70, "conditional_value_range": [80, 100], "assumptions_disclosed": true}
可支持：可报告相对该条件区间的折价并列脆弱参数。
不能支持：不能承诺价格会向模型价值收敛。

### counterexample — ES08.Q04.counterexample

合成输入：{"synthetic": true, "company_pe": 20, "peer_pe": 30, "sector_overpricing_possible": true}
可支持：相对同行折价可能与行业整体高估并存。
不能支持：不能仅以低于同行保证内在价值低估。

### missing — ES08.Q04.missing

合成输入：{"synthetic": true, "valuation_point": 100, "cashflow_evidence": null, "sensitivity": null}
可支持：经营依据和敏感性待补。
不能支持：不能宣称有稳健安全边际。

## 主要限制和行业待补

- 未定义价格和价值口径的安全边际百分比没有可比含义。
- 模型间数值接近不能证明独立支持，可能共享相同错误假设。
- 定量输入映射待补，不代表已能从事实库直接取数；方法不生成目标公司判断。
- 行业事件风险及具体投资者约束不由此通用方法代替。
