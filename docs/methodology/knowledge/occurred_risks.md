# 已发生风险事件与实际暴露

本方法为 ES06.Q03 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 建立事件时间线，分别保存事件发生日、披露日、主体、状态和来源，不把风险提示当事件。

2. 核对实际受影响合同、资产、收入或现金范围，金额、期限及应对行动有无落地。

3. 区分已实现损失、合理估计和待判定暴露，后续公告更正要保留前版和影响范围。

## 输入、支持关系与缺失处理

所需证据：事件公告、执行/判决/停产等状态及受影响业务和财务证据。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

风险清单列可能性，已发生事件需要独立事实与日期；风险金额也不自动等于损失。

缺发生状态或影响范围时标待核实，不用模板风险替代事件证据。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：公告确认某厂停产10天，受影响产线占20%，实际损失尚未量化。 可确认停产事件和范围，不能捏造已实现损失金额。

反例：年度风险章节写“原料可能涨价”，没有本期涨价或损失记录。 这是潜在风险，不能登记为已经发生的原料冲击。

缺失例：缺发生状态或影响范围时标待核实，不用模板风险替代事件证据。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
