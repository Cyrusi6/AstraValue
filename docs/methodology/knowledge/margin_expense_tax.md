# 毛利费用税负的变动桥接

本方法为 ES02.Q03 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 把收入成本与费用按同范围期间排列，确认毛利、经营利润、期间费用及所得税定义。

2. 分析产品/渠道结构、原料成本、费用投放及资本化变更，不能只把毛利变动归为涨价。

3. 对有效税负核对利润总额及所得税费用，分别解释优惠、递延、非应税项目和亏损基数；不把会计税率直接替代估值税率。

## 输入、支持关系与缺失处理

所需证据：收入成本费用分项、结构变化、所得税费用及税项调节。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

比率变化须由同口径分子分母和结构解释；利润为零/负及税收特殊事项会限制常规税率解释。

缺所得税调节或税前利润非正时保留税负解释缺口。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：收入100、成本60，次期同结构收入110成本66，毛利率均40%。 可说明收入成本同比增而毛利率未改善，进一步检查费用和税项。

反例：高毛利产品占比提高推升整体毛利率，却声称所有产品成本下降。 结构效应不足以支持全品成本改善，须分产品数据。

缺失例：缺所得税调节或税前利润非正时保留税负解释缺口。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
