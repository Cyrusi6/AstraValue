# 管理层任期、薪酬与变动

适用于 ES03.Q03 的跨行业通用分析。方法只指导取证与判断边界，不直接给公司结论。

## 执行步骤

1. 建立人员—职务—起止日期表，区分辞任公告日、实际离任日与继任生效日，注明兼任与关联关系。
2. 把薪酬拆成固定、绩效、股权和其他项目，区分报告期应计、支付和持股价值；同口径再跨年比较。
3. 检查绩效考核变量、事前门槛、追索安排和目标重设，比较目标与已披露结果，不能由薪酬高低直接断定能力。
4. 记录变动原因、交接与继任安排；频繁变动是核查线索，须以运营中断、审计问题等证据判断影响。

## 必需证据及用途

- 任命辞任及生效公告、履历与兼任
- 薪酬分项、绩效条件、结果和接任安排

缺绩效条件或薪酬范围，保留金额事实，不能判断薪酬是否与长期利益一致。

## 来源与边界

治理披露应包含董事资格、薪酬结构及变动，高管绩效和接任安排需联系长期目标。 来源：`SRC-OECD-GOVERNANCE-2023@2023`，PDF31–32/印刷29–30 §IV.A.5–6；PDF39/印刷37 §V.D.4–5。

国企任命、合伙制及跨国薪酬口径需行业/制度补充；不设统一任期或薪酬阈值。

OECD为非约束性治理原则；披露状态时间线、数量桥接与案例是项目综合方法，不冒充来源逐字条文或A股强制规定。案例与输入的时间/范围不能被省略。公开原文只本地缓存。

数量输入需从原披露提取并核对期间、单位和范围，现有指标映射未证明一致，标记 `pending`。不按相近字段名自动替换。
