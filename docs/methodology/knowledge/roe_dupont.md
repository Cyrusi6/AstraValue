# ROE与杜邦分解的口径和分母效应

本方法为 ES02.Q04 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 选择净利润/权益的归属范围并保持一致；归母收益配归母权益，期间收益配明确的期初或平均余额。

2. 在正且有经济含义的分母下，将同口径净利率×资产周转率×权益乘数写为代数桥接，三个分子分母必须完全约掉。

3. 解释利润、周转、杠杆和回购/减值压低权益的作用；负权益、近零权益或合并归属混用时停止常规ROE解读，ROIC另读专门方法。

## 输入、支持关系与缺失处理

所需证据：同范围归属利润、收入、平均资产/权益及回购/减值/范围变动。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

ROE分解是同口径恒等关系；借债回购缩小权益能提高比率，但不自动代表经营利润或资产效率提高。

缺归母权益或平均期时不使用总权益/期末值静默替代；负权益比率不正常排名。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：归母利润20、收入200、平均资产400、平均归母权益200：10%×0.5×2=10%。 可以复核杜邦乘积与直接ROE10%一致，再解释三个驱动。

反例：利润20不变，借款回购使可比权益从200降至100，ROE由10%到20%。 不能只凭ROE翻倍认定经营效率翻倍，分母及杠杆效应明显。

缺失例：缺归母权益或平均期时不使用总权益/期末值静默替代；负权益比率不正常排名。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
