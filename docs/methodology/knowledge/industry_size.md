# 行业规模增长的统计口径

本方法为 ES07.Q02 提供通用研究路径，返回方法与所需证据；不接收公司事实生成公司判断。

## 执行步骤

1. 先定义产品、地区、价值链环节、币种、数量单位及统计期间，再寻找可覆盖该范围的分母。

2. 区分终端消费、生产、出货、交易总额和收入净额；名义规模变化需检查价格与数量。

3. 比较多个可核定义的序列及修订，明确样本覆盖和估算方法；不同口径不直接拼接成长线增速。

## 输入、支持关系与缺失处理

所需证据：行业统计定义、总量覆盖、期间单位、名义价格和历史修订。保留文档、章节/页码或表行、披露日和实际期间；比较时先统一主体、币种单位及合并范围。

行业规模和增速只对定义范围成立；环节重复、价格变化及样本变化可能造成表面增长。

缺总体覆盖或口径定义时只能给样本规模，不伪造全行业分母。 定量计算需要的概念字段尚未证明和现有指标一一匹配，见目录中的映射待补输入，不把方法完整当作自动取数已可用。

## 独立合成案例

正常例：同范围实际销量从100到110、价格不变且样本覆盖稳定。 可说该统计口径销量增长10%，不自动等于每家公司增长10%。

反例：将生产端收入与批发、零售流水相加，称行业规模。 同一商品跨环节重复计量，不能作为终端行业总量。

缺失例：缺总体覆盖或口径定义时只能给样本规模，不伪造全行业分母。

这些是方法验证用的合成事实，不是目标公司的数据。来源、例子和判断边界由Agent审阅；程序测试只检查引用/关系等明确定义的条件，人工内容抽查另行记录。
