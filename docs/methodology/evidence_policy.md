# 证据与来源规则

> 目标规则更新：2026-09-08。依据用户已确认的“结构化数据优先、重要报告精读”方案。
>
> 本文描述待实施行为。[机器可读来源策略](../../config/methods/source_policy.json) 当前仍是旧版本，须与事实模型、消费选择器及测试一并迁移；修改本文不等于运行规则已切换。

## 1. 每类字段指定一个主要来源

- 公司结构化事实主要来自东方财富；BaoStock 负责日行情、估值及其实际覆盖、口径明确的常见财务指标。具体指标归属以待确认的字段表为准，同一标准字段不得同时安排两个默认主源。
- 主源返回的数据通过类型、日期、期间、单位、分页和必要的跨字段校验，即可进入分析。缺失、请求失败或响应校验失败时，才调用有顺序的免费备选；成功字段不得顺带双抓。
- 默认不做双源对账，不逐项核对 PDF，不主动追查每个正式更正版本。`缺少正式披露主源` 和 `只有一个供应商` 不构成不可消费原因。
- AKShare 等封装须登记真实上游。注册与使用应符合长期免费范围，限时试用或付费专享字段不作为必需依赖。
- 首版面向目标公司及同行，首次分批获取供应商可免费提供的全部历史与全部适用客观字段，之后只做增量更新；默认展示近五年和十二季度不限制入库范围。
- 来源或字段失败使用备选、缓存和明确缺口；恢复保持限速、有限重试与可续跑。未取得数据不由 LLM 补造。

## 2. 数据性质、状态与血缘

一类数据包括已记录的客观事实以及公式明确的确定性指标。平台概念标签、盈利预测、评级与观点、算法估计和 Codex 分析判断分别保存，不能因为使用同一接口就取得事实身份。

新目标模型须分开表达：

| 维度 | 表达内容 |
|---|---|
| 来源与取得方式 | 供应商结构化直采、重要报告抽取、公式计算等 |
| 数据性质 | 客观记录、确定性派生、估计、预测、平台标签或分析判断 |
| 质量与可消费性 | 通过、部分缺失、失败、实际冲突、不适用，以及受影响字段 |
| 版本与时间 | 来源版本、响应快照、获取时间、报告期、披露/生效时间、可得时间依据 |

“供应商直采且可消费”是已确认的行为，具体枚举名称待新 OpenSpec 定义。不得把它伪装成旧 `双源一致` 或 `权威单源`；原有七种状态和历史对账结论保留原语义，不覆盖旧快照。

- 结构化事实保留原始响应快照/hash、真实上游、接口与脱敏参数摘要、分页位置、行键、字段路径、原始名称和值、获取时间、标准字段、单位和期间；不强制存在 `document_id` 或页码。
- 报告抽取保留原文/hash、文档 ID、页码、表格或段落定位及解析版本。机器解析和 LLM 候选不自动等于人工确认。
- 公式计算保留输入记录和公式版本。覆盖不完整、分母定义不明或含假设的计算须标为估计或假设，不能假称客观实测。
- `未披露` 须有明确依据；接口未返回不等于公司没有披露。查询为空、字段缺失、来源失败、历史不可得与不适用分别记录；空值不填零。
- 取得多少适用字段、多少尚未归类、多少缺失必须可统计。保留未映射的原始字段并登记，不静默忽略新字段或用前 N 行代表全量。

## 3. 整理、版本和历史使用

- 统一年度、累计、单季、TTM、合并范围、币种、单位和指标定义；存量与流量分开，不能对所有字段套同一期间转换。
- 只执行定义成立的恒等式、合计和明显异常检查；舍入误差、亏损和行业特例按字段合同处理。
- 主源返回的新版本留存快照。数据到达顺序不能代替业务生效关系；预案不等于实施、计划不等于完成。
- 实际观察到的重大歧义或冲突保留双方，不平均，不静默覆盖。仅限制受影响的确定性输入；不为了制造对账证据默认调用第二源或重抓 PDF。
- 当前研究可使用供应商提供的历史序列，并注明是否有历史版本和可得时间证明。缺少证明不能充当严格 point-in-time 回测输入，但不因此阻断当前研究。
- 旧原文、哈希、响应、报告和快照保留。新来源规则只在明确版本边界后生效，不得倒改旧验收记录。

## 4. 原文选择

- 公告保留轻量目录；完整中文年报、中报获取正文并精读。
- 季报主要更新结构化数据，明显变化时定向阅读；重大事件和更正公告按研究问题触发正文读取。
- 独立审计 PDF、英文年报和内容重复的额外正文不再采集；已有内容复用，元数据与选择理由保留。
- 重要报告沿用 MinerU 精准解析 API 和现有适用解析器，保留页码关系，不恢复旧本地 OCR 流程。
- 结构化缺口不会自动开启全量公告正文归档，也不要求逐项找到正式披露才能消费供应商数据。
