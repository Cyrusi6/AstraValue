# 研报提价与现金分配计算 v1

执行规则：`src/analysis/research/distributions.py`；统一入口 `calculate`，MCP和CLI共享。计算记录绑定当前研究快照、公式版本、输入事实及原件哈希。原始冻结包不改写。

|方法|定义|输入边界|
|---|---|---|
|price_change|末次合同价 / 首次合同价 − 1|同一产品两份公告，首份调后价等于末份调前价，日期递增、价格为正；不把涨幅相加|
|payout_ratio|年度累计现金分红 / 同年度归母净利润|累计完整年度，利润为正；分红包含预案时原样保留该定义，回购不计入现金分红|
|dividend_yield|历史年度分红 /（参考股本 × 参考股价）|历史分红按当前市值折算，不是历史每股实际到账收益，也不是未来分红承诺|
|forecast_dividend_yield|历史年度分红 ×（1＋假设分红增长率）/（参考股本 × 参考股价）|明确未来十二个月、当前股本不变；增长率由模型提供并说明依据，可为−100%，不默认为0|

目前原文提取支持“销售合同价由…元/瓶调整为…”及“YYYY年度累计派发现金红利…亿元（口径说明）”的唯一匹配；金额由代码解析并换算，模型只选择证据ID。需要原件哈希验证和公司披露来源。其他表格或措辞返回明确处理缺口，不能手填未经核验的金额绕过。支持范围由披露格式决定，未宣称所有公司公告都已覆盖。

代码保留提取原句、期间、单位、事实定义、假设及完整精度结果；输出百分数是value×100，正文通过`{{value:计算ID.value}}`统一显示两位小数，计算及来源进入附录。该接口不把预测值写入历史指标库。
