## 3. 轻量范围与模型输入预算

### 3.1 期间与文件

- 主表展示最近 3 个完整年度和最近 8 个应需季度。以 `as_of`、上市时间及披露规则确定窗口，不能按数据库“最新有值”倒退窗口隐藏缺失。以本次固定日期为例：2023—2025 年，2024Q3—2026Q2。
- 同比、单季、TTM、平均余额需要的前置期间留在计算依赖中，仅对实际公式补齐；不为八个展示季度默认抓取全部历史。资产负债表按时点，流量按年度/单季，TTM另列，禁止混用。
- 常读原件：最新完整中文年报＋最新已披露中报；最新季报的结构化更新照常。历史报告、上年同期中报优先复用，需要同比解释、附注、异常、修订或具体风险时才读取/补取。
- 新的轻量任务不因全量基线要求而默认补齐五份年报及所有历史正文。原全量 profile 和其历史结果继续保留，旧任务的新网络请求也不得越过显式选定 profile。
- 治理资本事项：当前状态、近三年关键事件，以及更早开始但尚未结束的债务、担保、激励、诉讼、并购承诺。最新年报以后至 `as_of` 的必要公告目录须有刷新状态，未核查不能写“无重大变化”。
- 独立审计 PDF、英文年报停采规则不变；完整中文年报内部审计与附注保留；摘要不得代替全文。

### 3.2 六组核心输入

| 组 | 默认核心字段或证据 | 条件扩展／不得冒充 |
|---|---|---|
| A 业务 | 主体、实际业务、盈利及收入确认方式；产品/地区/渠道收入和成本、毛利；白酒销量、经销结构、客户供应商集中度 | 已披露才提供量价/集中度，缺分母不推算；核心优势用原文与可观察数据，不生成无来源判断 |
| B 财务 | 营收、营业成本、净利润、归母、扣非归母、销售/管理/研发/财务费用；经营/投资/筹资净现金流、购建长期资产现金；现金、总资产、归母/总权益、应收、存货、合同资产/负债、商誉、股本、有息债务组成 | 应收组成避免重复；借款/债券/租赁按已确认债务规则加总，组成不全不出“总有息债务”；EPS/加权股数按明确用途再选 |
| C 质量与风险 | 审计意见、受限现金、债务到期、减值、重大关联占款/担保/诉讼/处罚/问询；利润现金流背离、应收存货与收入变化 | 差异筛查只是阅读触发，不自动判定造假或重大风险；结构化无记录不证明无事项 |
| D 治理与资本 | 实控人、重要质押/控制变化、关键管理层变化、分红、回购、融资、重大投资/并购/激励的计划与实际 | 不装入全名册/全部交易明细；实际分配基数、实际支付与计划缺失时分开留缺口 |
| E 行业与驱动 | 白酒量价、产品结构、渠道/经销商、库存/合同负债中选择 2—4 个关键驱动；2—3 家同口径同行、必要外部统计 | 不默认要求所有行业指标；市场份额缺分母留缺，不用宏观数据代替；产品价格不是股票行情 |
| F 估值与约束 | 指定时点价格、市值、股本、实际适用的 PE TTM/PB/PS、分红输入；事实缺口、方法限制、待确认情景参数 | 不默认历史估值分位、DCF/ROIC/WACC/EV-EBITDA全套路线；只有明确启用时扩展历史、债务/折旧/利率等输入，不伪造合理价或安全边际 |

财务派生最小集合：收入/归母/扣非/经营现金流同季或年度同比、毛利率、归母净利率、各费用率、经营现金流/净利润、经营现金流减购建长期资产现金支出的代理值。有完整同口径输入才计算；该代理值不命名为 FCFF/FCFE。ROE 仅在净利润与权益范围匹配、平均余额依赖完整时启用，供应商加权 ROE 独立标注。

全部字段、证据槽位、触发条件登记稳定 ID、问题 ID、主要来源、单位/主体/期间规则、必需/条件、排序。六组映射：A→ES01，B/C→ES02，C/D→ES03，D→ES04，F→ES05，A/C/E→ES06，E→ES07，F及全组缺口→ES08。

### 3.3 预算与保留优先级

- `core-pack.md` 目标 8,000—15,000 token，15,000 为默认上限；材料少时不凑下限。记录实际 tokenizer/版本、计数范围。tokenizer 不可用时输出明确的保守估计及算法，不能把估计当精确计数。
- 只把核心包交给模型；全量 facts、54 题明细及原文索引留本地。精确数字、单位、期间、核心缺口、重大已知风险、冲突与引用不得因预算而静默删除。
- 先删重复表达和无关段落，再把可选明细改为引用，最后缩减非核心历史展示。原始期间和证据仍留附件。每个省略项注明原因；必要信息仍超限时返回 `budget_exceeded`，不截断后宣称完整可读。
- 证据默认按主题、表格和期间挑选，段落去重，保留足够上下文、否定/条件语句、表头、单位和续表关系。关键词命中只用于候选发现，不能直接标为已回答。
- 检索默认单次最多约 2,000 token，可按页/表继续分页；提供总命中、截断和下一页标识，不自动把剩余正文全部加载。不新增向量库、RAG 服务或常驻模型服务；使用已有解析索引与确定性筛选即可。

| `evidence-index.jsonl` | 短引用→原件哈希、文件位置、来源 URL、页/表/单元格或 snapshot/row/field、解析版本、证据性质、语义状态；不复制全部原文 |

`ready` 仅用于已完成相应字段/证据核验的要求；`source_text_available`、`pending`、有依据的 `not_applicable` 保持区分。core/conditional/deferred 是范围路由，不替代质量状态。打包技术成功、核心充分性、全量54题覆盖分别报告，不设“整体95%”之类掩盖风险的单一指标。
