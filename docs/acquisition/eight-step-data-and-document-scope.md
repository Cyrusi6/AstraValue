## 1. 采集原则与范围

每项输入必须对应 ES01–ES08 的具体问题、确定性计算或必要的身份/日期上下文。主要采集完整财报及附注、经营信息、治理与资本事项、行业变量和必要估值输入。

| 选择类别 | 操作含义 |
|---|---|
| 必取 | 在选定公司、适用业务和所需期间内，复用有效缓存；缺少时获取结构化数据或指定正文。不存在适用事项时保留依据，不制造文件 |
| 按需取 | 有明确问题、缺失输入、重大变化或未结束事项时取得，记录触发原因和范围；不自动扩大成整类全历史 |
| 仅目录 | 保存标题、日期、类型、链接、附件信息及选择原因；未下载正文属于正常状态 |
| 默认不取正文/数据 | 不为此类内容主动发起请求；已由必要目录发现的条目可保留目录，已归档证据不删除 |

默认分析窗口沿用五个完整年度和十二个季度。同比、单季、TTM、平均余额等计算需额外保存前置期间，不能机械截断到展示窗口。已有更长历史直接复用；新采集的额外历史由行业周期、估值区间、旧事项或具体问题确定。公司和同行使用一致的研究口径，但不强迫不存在的行业专属数据变成通用必填项。

文件基线优先为五份完整中文年报、最新中报及上年同期中报；更早中报在解释历史变化、补附注或其他具体问题需要时取得。例如截至 2026-09-13、公司已披露 2026 年中报时，默认年报为 2021–2025 年，中报为 2026/2025 年，十二季度为 2023Q3–2026Q2。计算所需更早余额/同季数据另补；这是一家公司样例，不把尚未披露或上市前不存在的报告列为已取得。

原始响应中的附带字段可以随快照保存；这不使它们自动成为默认消费事实、后续补采目标或业务覆盖分子。接口支持选字段时在请求端限制。一个字段只指定一个主要来源，主源有效时不再额外抓同义备选。

## 3. 文件格式、原件与解析结果

| 格式 | 应如何取得与保存 | 提取定位与能力边界 |
|---|---|---|
| JSON / SDK 返回表 | 按选定字段/期间取得接口结果，保存原始 HTTP 响应或明确标注的 SDK 序列化快照 | 公司、行键、字段路径、响应时间、参数和哈希；SDK 序列化字节不能称为供应商原生网络报文 |
| PDF | D01–D19 中被选择的官方原件，保留整份原文件与实际来源 URL | 提取页码、章节、表头、单位、表下注释、续表、主体和期间；只读相关章节不等于删除其余原件 |
| HTML / XHTML | 来源实际发布网页全文时保存原始内容及引用关系；附件另按选择规则取得 | 段落、表格、标题、发布日期、页面 URL 和内容版本；HTML 拦截/错误页不当报告 |
| XLSX / XLS / CSV | 只取官方行业统计、利率或经营问题对应的原始表，保留原文件 | 工作表、单元格/行列、表头、单位、注释及统计范围；不能把本系统导出的 Excel 当上游证据。具体来源/格式适配仍需验证 |
| DOCX / DOC | 仅在必要官方材料以此格式发布且没有等价已缓存正文时按需保存 | 保留原件；解析或转换结果标为派生件并绑定转换版本。不能因文件能下载便宣称当前解析器已支持 |
| XML / XBRL | 对确有公开入口、能满足特定财务缺口的来源另行验证后按需接入 | 保存 taxonomy、context、unit、维度和扩展标签；当前项目未证明已具备完整 XBRL 获取/解析能力，不作为默认必需下载 |
| PNG / JPEG / 扫描页 | 仅保留被选报告中的必要表格图、扫描页，或正式发布的必要图片原件 | OCR/表格识别是派生结果，保留页面/图片定位与单位检查；不采无关宣传图，不用截图替换能获取的原文件 |
| ZIP 等附件包 | 默认不整包归档；若必要文件只在官方包内，先登记具体成员需求和适配缺口 | 记录成员名与原包关系；尚无已验收的通用包处理能力，不把附件包存在视为全部文件必须取 |

扩展名、响应 MIME 和实际内容应核对。原文件、解析文本/表格、规范事实、计算结果分开保存；SQLite、DuckDB、Parquet、JSONL 是本地存储/投影形式，不是要求爬取的上游文件种类。已有有效文件按哈希复用，已有有效解析按原文件哈希与解析版本复用；需要解析的 PDF 沿用当前已配置能力，不因格式清单新增未经验证的解析服务。

状态分别记录为：已发现、仅目录/按策略未取、待下载、下载失败、已下载、待解析、解析失败、已解析待语义整理、可消费、存在具体缺口。不能把下载成功或 OCR 成功等同于财务字段和全部附注已经可用。

## 8. 文件时间范围、版本与增量

1. D01/D02 先满足分析窗口及计算输入。更早报告为周期、公司沿革、未结束事项或具体问题服务；不因已有全历史接口或目录就自动解析全部材料。

4. 研究对象和同行按业务可比性确定。同行财务、业务与估值使用一致口径；行业统计和必要交易日历只保存共享数据及各自引用。
