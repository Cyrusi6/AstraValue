## 代码与计算边界

共享 `prepare_processing` 服务从已绑定的投影和有定位原件生成候选快照，核验后用既有 `adopt_snapshot` 显式采用。CLI与MCP共用服务。此轮证据选择描述符已准备好；公司冷启动和自动补采全链路仍不在已完成范围。

`calculate(method="financial_summary", bindings={})` 计算实际年度跨度CAGR与合并杜邦。2021—2025年有五个观测、四个间隔；杜邦采用合并净利润和期初期末平均总权益，含少数股东，不冒充加权归母ROE或ROIC。输入不足或分母不满足条件时保留缺口。

常规图新增合并杜邦、已采用历史PE与同日同行PE；连同收入利润、利润现金流、估值敏感性共六图。所有图使用当前研究绑定的事实或计算结果。定制沙盒和现金流瀑布仍未完成，没有为了验收强加到本报告。

报告组装修复了价格采集时间误显示为行情日期、重复组装时假设来源时间戳冲突、模型正文替换后Excel核心期间表为空、PE情景被通用现金流模型缺参数提示混淆等问题。正文修改复用原计算，不重新采集。
