## 证据边界

- `9201` 是供应商本次查询的空响应，保存为 `eastmoney_9201_empty`；它不表示公司层面的“无事项”。
- CNINFO 证据必须按报告期、页面、原文快照哈希和来源 URL 追溯；读取应由研究工作区按主题触发，不恢复全量报告下载。
- 9 项中 `goodwill` 尚无已登记 filing-check；其余主题的原文覆盖也只覆盖表中报告期和语义范围，不等同于 API 字段完整覆盖。
