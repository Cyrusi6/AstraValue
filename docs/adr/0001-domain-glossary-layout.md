# ADR-0001：六域术语表与任务按需读取

日期：2026-10-08。状态：已采纳。决策依据：用户确认接入 `GLOSSARY-MAP.md` 与每域一份术语表的方案。

## 背景

当前主链涉及来源获取、事实整理、研究判断、计算、报告和知识方法。来源快照与研究快照、不同覆盖状态，以及事实、陈述和假设在代码及契约中各有含义，原 Agent 入口仍描述根目录单表布局。

## 决策

- 根 `GLOSSARY-MAP.md` 维护领域职责、代码定位、任务读取路径和跨域导航。
- `docs/domains/{acquisition,facts,research,calculation,reporting,knowledge}/GLOSSARY.md` 分别维护六域概念；其他域通过链接使用该定义。
- 六域用于组织文档。现有代码目录、运行时接口、数据库和历史产物继续按对应版本的合同工作。
- 公司治理的主体、任期、持股、关系和事件重建先作为事实域专项章节，治理评价归研究域。
- 产品职责与范围查 `项目总计划.md`，字段、公式、枚举及版本约束查对应契约和机器配置，当前运行能力查代码、测试及运行证据。术语表提供解释和定位；发现差异时逐项报告，并更新对应依据。
- `AGENTS.md` 指向地图与领域读取规则；`CLAUDE.md` 继续通过 `@AGENTS.md` 复用入口。读取只覆盖任务相关域及本次改变涉及的依赖。

## 影响与维护

概念由所属域维护一次，减少同名误解与重复定义；维护人需在涉及含义的变更中同步术语表和跨域链接。继续引用已有字段与状态合同，保留未解决分歧。

当某专项形成大量独有概念和稳定输入输出时，可新增术语表并更新地图；八步章节、技术入口及目录数量本身不决定领域切分。职责、数据语义或兼容性改变时追加相关 ADR，原决策保留历史身份。

## 检查依据

按[茅台研究链术语核查](../domains/moutai-trace.md)检查对象归属和跨域引用；文档检查覆盖地图、术语表、ADR 与 Agent 入口的路径及锚点。
