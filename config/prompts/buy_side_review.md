# 统一研究审阅提示词 v5

审阅完整研报及图表，判断它是否足以支持清晰的投资观点。先审金融论证，再检查数值、语言和成品。只报告具体问题，区分影响结论或理解的必改项与可选精修。

1. **预测依据。** 最重要的假设为什么是这个幅度？经营因素如何传到利润？方向有理由但量级悬空时，要求补经营拆解或关键参数敏感性，不机械要求完整DCF。达标目标反推不能证明预测可达，描述性数据不能跳过机制直接证明经营优势。
2. **估值与回报。** 方法是否适合公司，倍数或折现假设有什么经济依据？盈利预测期、价值时点和持有期是否清楚？分红是重要投资理由时，是否与价格变化按同一期间评价且未重复计入？
3. **判断与行动。** 结论是否由前述证据和假设支持，是否明确解释风险补偿与行动倾向？报告是否给出了唯一总体方向（偏多、中性或偏空），并在摘要第一段直接说明当前价格是否提供足够安全边际？“中性”是否有基准回报、要求回报和上下行情景的数字依据，而不是默认避险用语？是否分别给出已有持仓和新增资金的动作，并解释两者不同的原因？发现“评级中性但实际建议回避、等待或减仓”而未解释时，列为必改项。评级变化应结合经营及当时价格。允许有依据的自主情景，不因尚未成为事实而退回，不替作者指定评级或参数。
4. **事实与数值。** 结合计算和引用检查，核对重要数值、期间、单位、图文与来源一致性。发现错误指出位置、正确口径及影响，要求修正或重算；不通过增加免责文字处理。计算正确不能替代论证充分。
5. **表达与成品。** 第1—4章没有逐章自辩，第5章评价风险补偿，第8章先给唯一总体方向，再给已有持仓和新增资金的行动，且不重复情景数值。全篇风险及调整条件仅在第6章一次、最多300个非空白字符。删掉工程日志、重复提醒和空泛收尾。看完每页，检查图表是否支持论点、期间与轴单位、跨页及可读性；附录能凭文件名、日期、原文页码或配套工作表定位来源。探索性质保留简短标记，方法细节放附录。

反馈写清“哪一处、为什么影响理解或判断、最小修改是什么”，不固定要求凑满问题。修改后复核受影响的判断、数值及页面；没有实质问题即可交付，不重新要求全篇添加反证。研究判断或证据仍不足时如实说明具体影响，不把格式完整当作研究完成。
